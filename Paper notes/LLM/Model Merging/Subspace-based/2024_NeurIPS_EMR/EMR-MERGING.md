# EMR-MERGING Tuning-Free High-Performance Model Merging

## Abstract

预训练-微调范式的成功带来了大量模型权值的释放。在这种情况下，合并针对不同任务进行微调的模型，以使单个模型具有多任务功能，由于其实用性而受到越来越多的关注。现有的模型合并方法通常存在:(1)显著的性能下降或(2)需要通过额外的数据或训练进行调优。本文对现有的模型合并范式进行了反思和分析。我们发现，使用单个模型的权重很难模拟所有模型的性能。为了解决这个问题，我们提出了ELECT, MASK & RESCALEMERGING (emr - merge)。我们首先(a)从所有模型权重中选择一个统一的模型，然后(b)生成非常轻量级的特定于任务的调制器，包括掩模和重新缩放器，以分别对齐统一模型和每个特定模型之间的方向和幅度。emr合并无需调优，因此不需要数据可用性或任何额外的训练，同时显示出令人印象深刻的性能。我们发现emr - merge在不同的经典和新建立的设置下，包括合并不同数量的视觉模型(最多30个)、NLP模型、PEFT模型和多模态模型，与现有的合并方法相比，表现出了出色的性能。

### **Introduction 详细解析**  

#### **1. 研究背景与动机** - **预训练-微调范式的普及**：    

预训练模型（如BERT、ViT）在多个领域取得成功，通过微调可适配不同任务。然而，独立存储和部署多个模型导致**高存储与计算成本**。 

- **多任务学习（MTL）的局限性**：    MTL通过联合训练实现多任务能力，但需访问大量标注数据（隐私问题）且计算成本高昂（尤其对大模型）。 

- **模型合并的潜力**：    通过合并已有模型权重而非重新训练，可低成本获得多任务模型。但现有方法存在**性能严重下降**或**依赖调参**的问题。 

#### **2. 现有方法的不足** - **三类主流方法**：    

1. **加权平均法**（如Fisher-Merging、RegMean）：依赖预计算矩阵（如Fisher信息），性能有限。    
2. **任务向量法**（如Task Arithmetic、Ties-Merging）：通过任务向量叠加合并，但需手动调参或额外训练。    
3. **预处理技术**（如DARE）：随机丢弃参数，仅在少量任务中有效。 
4. **核心问题**：    
5. - 单一模型难以同时拟合所有任务（如加权平均在8个视觉任务中平均准确率仅**65.8%**，比个体模型低**24.7%**）。    
6. - 现有方法依赖数据或调优（如AdaMerging++需验证数据），限制实用性。  

#### **3. 创新点与解决方案** 

- **新范式提出**：    作者认为现有方法的根本问题在于**试图用单一模型模拟所有任务**。
- 提出新范式：    $  W_{\text{uni}}, [E_1..E_N] = \mathcal{M}'([W_1..W_N])  $    即从模型中提取统一部分 $W_{\text{uni}}$，并为每个任务保留轻量级特定部分 $E_i$。 - **EMR-MERGING的核心步骤**：    
- 1. **ELECT**：通过符号聚合和最大绝对值选择统一任务向量，减少干扰。    
  2. **MASK**：生成1-bit掩码，对齐方向（符号一致）。    
  3. **RESCALE**：计算缩放因子，匹配参数幅度。

### **方法部分详细解析**


#### **1. 动机：为何需要新方法？**
- **问题**：  
  现有模型合并方法（如加权平均、任务向量叠加）试图生成一个单一模型 $W_M$，但无法同时拟合所有任务的特性，导致性能下降（如8个视觉任务中加权平均准确率仅**65.8%**，比个体模型低**24.7%**）。
- **关键观察**：  
  任务向量（$\tau_i = W_i - W_{\text{pre}}$）的符号和幅度差异是性能下降的主因。例如，不同任务的参数符号冲突（如一个任务增加权重，另一个减少）导致干扰。


#### **2. 核心范式：统一模型 + 任务特定调制器**
作者提出新范式：  
$
W_{\text{uni}}, [E_1..E_N] = \mathcal{M}'([W_1..W_N])
$  

- **统一模型 $W_{\text{uni}}$**：提取所有任务的共享部分，减少干扰。  
- **任务特定调制器 $E_i$**：轻量级参数（掩码和缩放器），对齐方向和幅度。


#### **3. EMR-MERGING 步骤详解**

##### **步骤1：ELECT（选择统一任务向量）**
- **目标**：从所有任务向量中选出一个统一向量 $\tau_{\text{uni}}$，保留最大共享信息。  
- **操作**：  
  1. **符号聚合**：计算所有任务向量的符号总和，生成符号向量 $\gamma_{\text{uni}} = \text{sgn}(\sum_i \tau_i)$。  
  2. **最大绝对值选择**：对每个参数位置，选择与 $\gamma_{\text{uni}}$ 符号一致的最大绝对值，生成 $\epsilon_{\text{uni}}$。  
  3. **统一向量**：$\tau_{\text{uni}} = \gamma_{\text{uni}} \odot \epsilon_{\text{uni}}$。  
- **示例**：  
  若两个任务的参数符号分别为正和负，符号总和为正，则保留正符号的最大绝对值。

##### **步骤2：MASK（对齐方向）**
- **目标**：消除统一向量与个体任务向量的符号冲突。  
- **操作**：  
  对每个任务 $i$，生成掩码 $M_i$，其中：  
  $
  M_i = (\tau_i \odot \tau_{\text{uni}} > 0)
  $  
  符号一致的参数保留（1），冲突的置零（0）。  
- **效果**：  
  掩码后，统一向量与任务向量的符号冲突减少**30%**（如图4(a)所示）。

##### **步骤3：RESCALE（调整幅度）**
- **目标**：匹配统一向量与个体任务向量的参数幅度。  
- **操作**：  
  计算缩放因子 $\lambda_i$，使掩码后的统一向量平均绝对值与原任务向量相等：  
  $
  \lambda_i = \frac{\sum |\tau_i|}{\sum |M_i \odot \tau_{\text{uni}}|}
  $  
- **效果**：  
  缩放后，L2距离降低**30%**，余弦相似度提升**0.3**（如图4(b)-(c)所示）。


#### **4. 理论分析**
- **距离公式**：  
  合并后模型与个体任务的距离定义为：  
  $
  \text{Dis} = \frac{1}{N} \sum_{i=1}^N \|\tau_i - \tau_{\text{uni}}\|^2
  $  
- **掩码的作用**：  
  应用掩码后，距离 $\text{Dis}^M \leq \text{Dis}$，因为冲突符号的参数被置零，减少干扰。  
- **缩放的作用**：  
  应用缩放后，距离 $\text{Dis}^{M,\lambda} \leq \text{Dis}^M$，通过幅度调整进一步优化匹配。


#### **5. 实验分析**
- **可视化验证**：  
  - **t-SNE**：EMR-MERGING的特征分布更接近个体模型（如图3(a)）。  
  - **Grad-CAM**：注意力区域更聚焦目标（如图3(b)）。  
- **消融实验**：  
  | 方法               | 平均准确率 | 提升幅度 |  
  |--------------------|------------|----------|  
  | 仅ELECT            | 59.3%      | -        |  
  | ELECT + MASK       | 86.8%      | +27.5%   |  
  | ELECT + RESCALE    | 71.9%      | +12.6%   |  
  | ELECT + MASK + RESCALE | **88.7%** | +29.4%   |  


#### **6. 算法流程**
```python
输入：微调模型 W₁..W_N，预训练模型 W_pre  
输出：统一向量 τ_uni，任务掩码 M₁..M_N，缩放因子 λ₁..λ_N  

1. 生成任务向量：τ_i = W_i - W_pre  
2. ELECT步骤：  
   - γ_uni = sgn(Στ_i)  
   - 对每个参数位置 p：  
     τ_uni[p] = γ_uni[p] * max(|τ_i[p]| where γ_uni[p]·τ_i[p] > 0)  
3. MASK步骤：  
   M_i[p] = 1 if τ_i[p]·τ_uni[p] > 0 else 0  
4. RESCALE步骤：  
   λ_i = sum(|τ_i|) / sum(|M_i ⊙ τ_uni|)  
```


#### **关键问题思考**
1. **Q：为何选择符号和幅度作为调整维度？**  
   **A**：符号冲突直接导致参数抵消（如正+负=接近0），而幅度差异影响模型响应强度，两者是任务向量差异的核心因素。

2. **Q：掩码的稀疏度如何？**  
   **A**：在8个视觉任务中，掩码平均稀疏度约**70%**（即30%的参数被置零），但仍保留足够信息恢复性能。

3. **Q：缩放因子的取值范围？**  
   **A**：在ViT-B/32实验中，λ_i介于0.73-0.80之间（如MNIST为0.7981），表明统一向量掩码后的幅度需适度放大以匹配个体任务。

EMR-MERGING通过**符号对齐**和**幅度调整**两步，在无需调优的情况下显著提升模型合并性能。其创新点在于将统一模型与轻量级调制器结合，解决了传统方法无法平衡多任务特性的问题，为高效多任务模型设计提供了新思路。

#### **2. ELECT步骤公式解析**
**目标**：从所有任务向量中选出统一向量 $ \tau_{\text{uni}} $。

##### **公式1：符号向量聚合**
$
\gamma_{\text{uni}} = \text{sgn}\left(\sum_{i=1}^N \tau_i\right)
$

- **操作**：  
  对每个参数位置 $ p $，计算所有任务向量的符号总和，取符号作为 $ \gamma_{\text{uni}}[p] $。  
  - 若总和为正，则 $ \gamma_{\text{uni}}[p] = +1 $；  
  - 若总和为负，则 $ \gamma_{\text{uni}}[p] = -1 $；  
  - 若为0，通常取0（文档未明确，但实验中可能忽略或处理为0）。  
- **作用**：保留多数任务的符号方向，减少符号冲突。

##### **公式2：最大绝对值选择**
$
\epsilon_{\text{uni}}[p] = \max_{i} \left( |\tau_i[p]| \cdot \mathbb{I}(\gamma_{\text{uni}}[p] \cdot \tau_i[p] > 0) \right)
$
- **操作**：  
  对每个参数位置 $ p $，遍历所有任务 $ i $，若 $ \gamma_{\text{uni}}[p] $ 与 $ \tau_i[p] $ 符号一致（即乘积为正），则保留 $ |\tau_i[p]| $，否则置0。最终取所有任务中的最大值作为 $ \epsilon_{\text{uni}}[p] $。  
- **作用**：确保 $ \tau_{\text{uni}} $ 在统一符号方向上具有最大的幅度，减少信息丢失。

##### **公式3：统一任务向量**
$
\gamma_{\text{uni}} \odot \epsilon_{\text{uni}}
$
- **操作**：  
  逐元素相乘 $ \gamma_{\text{uni}} $ 和 $ \epsilon_{\text{uni}} $，得到 $ \tau_{\text{uni}} $。  
- **示例**：  
  假设 $ \gamma_{\text{uni}}[p] = +1 $，$ \epsilon_{\text{uni}}[p] = 5 $，则 $ \tau_{\text{uni}}[p] = +5 $。


#### **3. MASK步骤公式解析**
**目标**：消除统一向量与个体任务向量的符号冲突。

##### **公式4：掩码生成**
$
M_i = (\tau_i \odot \tau_{\text{uni}} > 0)
$
- **操作**：  
  对每个参数位置 $ p $，若 $ \tau_i[p] $ 与 $ \tau_{\text{uni}}[p] $ 符号一致（点积为正），则 $ M_i[p] = 1 $，否则 $ M_i[p] = 0 $。  
- **示例**：  
  若 $ \tau_i[p] = +3 $，$ \tau_{\text{uni}}[p] = +5 $，则 $ M_i[p] = 1 $；若 $ \tau_{\text{uni}}[p] = -5 $，则 $ M_i[p] = 0 $。


#### **4. RESCALE步骤公式解析**
**目标**：匹配统一向量与个体任务向量的参数幅度。

##### **公式5：缩放因子计算**
$
\lambda_i = \frac{\sum_{p=1}^d |\tau_i[p]|}{\sum_{p=1}^d |M_i[p] \cdot \tau_{\text{uni}}[p]|}
$
- **操作**：  
  分子为任务向量 $ \tau_i $ 的所有参数绝对值之和，分母为掩码后的统一向量绝对值之和。  
- **示例**：  
  若 $ \sum |\tau_i| = 100 $，$ \sum |M_i \odot \tau_{\text{uni}}| = 80 $，则 $ \lambda_i = 1.25 $。


#### **5. 理论分析公式**
**目标**：证明掩码和缩放可降低合并模型与个体任务的距离。

##### **公式6：初始距离**
$
\text{Dis} = \frac{1}{N} \sum_{i=1}^N \|\tau_i - \tau_{\text{uni}}\|^2
$
- **定义**：合并模型与所有个体任务向量的平均L2距离。

##### **公式7：掩码后的距离**

$
\text{Dis}^M = \frac{1}{N} \sum_{i=1}^N \|\tau_i - M_i \odot \tau_{\text{uni}}\|^2
$
- **推导**：  
  $
  \text{Dis}^M = \text{Dis} - \frac{1}{N} \sum_{i=1}^N \sum_{p: M_i[p]=0} |\tau_{\text{uni}}[p]|^2
  $  
  由于 $ M_i $ 置零冲突符号的参数，$ \text{Dis}^M \leq \text{Dis} $。

##### **公式8：掩码+缩放后的距离**
$
\text{Dis}^{M,\lambda} = \frac{1}{N} \sum_{i=1}^N \|\tau_i - \lambda_i \cdot M_i \odot \tau_{\text{uni}}\|^2
$
- **推导**：  
  对 $ \lambda_i $ 求导并令导数为零，可得 $ \lambda_i = \frac{\sum |\tau_i|}{\sum |M_i \odot \tau_{\text{uni}}|} $，此时 $ \text{Dis}^{M,\lambda} \leq \text{Dis}^M $。


#### **6. 关键问题解答**
1. **Q：符号函数 $ \text{sgn} $ 的实现细节？**  
   **A**：对于实数 $ x $，$ \text{sgn}(x) = 1 $ 若 $ x > 0 $，$ -1 $ 若 $ x < 0 $，0若 $ x = 0 $。在实际操作中，由于浮点精度问题，可能对接近零的值进行处理（如设置阈值）。

2. **Q：掩码 $ M_i $ 的稀疏度如何？**  
   **A**：在8个视觉任务中，平均稀疏度约70%（即30%的参数被保留）。例如，ViT-B/32模型的掩码稀疏度为69.94%-71.95%（见附录表16）。

3. **Q：缩放因子 $ \lambda_i $ 的取值范围？**  
   **A**：在ViT-B/32实验中，$ \lambda_i $ 介于0.73-0.80之间（如MNIST任务为0.7981），表明统一向量掩码后的幅度需适度放大以匹配个体任务。


#### **7. 示例说明**
假设两个任务的参数如下：
- 任务1：$ \tau_1 = [+3, -2, +4] $
- 任务2：$ \tau_2 = [-1, +5, +3] $

**ELECT步骤**：
1. 符号总和：$ \sum \tau = [+2, +3, +7] $ → $ \gamma_{\text{uni}} = [+1, +1, +1] $
2. 最大绝对值选择：
   - 参数1：任务1（+3）与符号一致 → 取3
   - 参数2：任务2（+5）与符号一致 → 取5
   - 参数3：任务1（+4）和任务2（+3）均与符号一致 → 取4
3. $ \tau_{\text{uni}} = [+3, +5, +4] $

**MASK步骤**：
- 任务1的掩码 $ M_1 $：
  - 参数1：+3·+3 > 0 → 1
  - 参数2：-2·+5 < 0 → 0
  - 参数3：+4·+4 > 0 → 1
  - $ M_1 = [1, 0, 1] $

**RESCALE步骤**：
- 任务1的缩放因子：
  - $ \sum |\tau_1| = 3 + 2 + 4 = 9 $
  - $ \sum |M_1 \odot \tau_{\text{uni}}| = 3 + 0 + 4 = 7 $
  - $ \lambda_1 = 9/7 ≈ 1.2857 $


### **总结**
EMR-MERGING通过符号对齐（$ \gamma_{\text{uni}} $）、最大绝对值保留（$ \epsilon_{\text{uni}} $）、掩码（$ M_i $）和缩放（$ \lambda_i $）四个关键步骤，系统性地解决了模型合并中的符号冲突和幅度差异问题。数学推导与实验结果共同验证了该方法的有效性，为多任务模型合并提供了理论与实践的双重支持。
