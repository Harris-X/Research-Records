# Model Merging for Multi-Target Domain Adaptation

### 一段话总结

本文聚焦场景理解模型的多目标域适应问题，**提出无需训练数据的模型融合方法**。该方法针对传统方法需同时访问所有目标域数据的缺陷，从融合模型参数和模型缓冲区两方面展开。通过实证分析发现基于相同预训练权重的模型线性连接性良好，简单中点融合参数即可；对于模型缓冲区，利用高斯先验估计新统计量。实验结果表明，在多个数据集上，该方法性能与数据组合训练基线相当，在使用 ResNet101 骨干网络时，相比最强单目标域适应模型，调和均值提升显著，如在特定实验中提升了 + 5.6% ，且在多目标域适应任务上优于现有方法。
