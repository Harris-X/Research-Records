**详细总结**

**研究背景**：预训练大模型全量微调资源消耗大，LoRA 微调因高效被广泛应用。在多任务场景下，学习多个任务特定 LoRAs 后需合并为统一适配器，但现有 LoRA 合并方法存在问题。线性合并基于各向同性假设不切实际，基于真实分布的合并方法虽改进假设，但仍有粗糙假设、大量样本需求和优化不平衡的局限。

**相关工作**：参数高效微调（PEFT）方法多样，LoRA - tuning 是其中应用广泛的技术。LoRA 合并旨在将多个 LoRAs 合并为一个统一适配器，现有方法包括线性合并和基于真实分布的合并方法，但都存在不足。

**IterIS 方法**

**LoRA 合并定义与现有方法**：给定预训练模型和多个任务，得到多个任务特定 LoRAs，合并后得到统一适配器。线性合并通过线性组合参数创建统一适配器，基于真实分布的合并方法利用样本推理获取输入特征来优化，但都有缺陷。

**IterIS 算法**：提出 IterIS 算法，通过迭代推理求解框架，每次迭代提取统一适配器输入特征，更新优化目标并求解。引入正则化项减少样本需求，仅需 1 - 5% 的未标记样本，使用自适应权重平衡优化过程。利用深度学习模型结构，算法收敛快，实验中设置最大迭代次数为 20。

**实验**

**文本到图像扩散模型**：利用 Stable Diffusion v1.5 和 Dreambooth - LoRA，在多概念定制任务上，以 CLIP - large - patch14 评估，对比线性合并等方法。**IterIS 在图像对齐和文本对齐指标上优于线性合并，与 custom diffusion 相比也有优势**。

**视觉语言模型**：对 BLIP - image - captioning - base 进行 LoRA 微调，在多风格字幕生成任务上，用风格准确率等指标评估，对比多种基线方法。**IterIS 在正负风格字幕生成的准确率上远超其他方法**。

**大语言模型**：在域内任务集成和多任务集成场景，分别用 FLAN - t5 - large 和 FLAN - t5 - base 模型，以 F1 分数和准确率等评估，对比线性合并和 RegMean 等方法。**IterIS 在大多数任务组合上表现更优**。

**结论**：IterIS 是一种有效的 LoRA 合并算法，通过迭代推理求解框架和层更新，在多领域优于基线方法。未来计划扩展算法应用于其他 PEFT 方法，探索 LoRA 合并优化公式的新视角。

**关键问题**

**IterIS 与传统 LoRA 合并方法相比，最大的优势是什么？**：IterIS 最大的优势在于其通过迭代推理求解框架、引入正则化项和自适应权重，有效解决了传统方法中粗糙假设、大量样本需求和优化不平衡的问题。在多个实验任务中，IterIS 在性能上显著超越传统方法，且收敛速度快，计算和内存效率高。

# IterIS 方法详解

## 一、方法概述

IterIS（Iterative Inference - based Solution）是一种用于 LoRA（Low - Rank Adaptation）合并的创新方法。其核心在于将 LoRA 合并过程构建为一个高级优化问题，通过迭代推理求解框架、高效的正则化项引入以及自适应权重的使用，旨在解决传统 LoRA 合并方法中存在的粗糙假设、大量样本需求和优化目标不平衡等问题 ，从而实现更高效、准确的 LoRA 合并。

## 二、方法核心内容与公式符号解释

### （一）LoRA 合并定义

给定一个预训练模型$M$，以及$n$个任务$\{T_1, T_2, \cdots, T_n\}$。针对每个任务$T_i$，通过 LoRA 微调得到对应的任务特定 LoRA 参数$\{\Delta M_{T_i}\}_{i = 1}^n$。LoRA 合并的目标就是将这些任务特定的 LoRA 参数合并为一个统一的适配器$\Delta M_{unified}$，使得合并后的模型$M + \Delta M_{unified}$能够在多个任务上都有良好的表现。

### （二）现有 LoRA 合并方法及缺陷

**线性合并**：线性合并是一种简单直接的 LoRA 合并方式，其通过线性组合各个任务特定 LoRA 的参数来创建统一适配器，公式表示为$\Delta M_{unified} = \sum_{i = 1}^n \alpha_i \Delta M_{T_i}$，其中$\alpha_i$是权重系数，满足$\sum_{i = 1}^n \alpha_i = 1$。这种方法基于各向同性假设，即假设所有任务特定 LoRA 的参数在特征空间中具有相同的重要性和分布，然而在实际情况中，这一假设并不成立，导致合并效果不佳 。

**基于真实分布的合并方法**：此类方法通过利用样本推理获取输入特征，以改进合并过程。它们通常基于真实数据分布来优化合并后的适配器，但仍存在粗糙假设，并且需要大量样本进行训练，同时优化目标也存在不平衡的问题。

### （三）IterIS 算法

**迭代推理求解框架**

**初始设定**：初始化统一适配器$\Delta M_{unified}^0$，通常可以设为零矩阵或随机矩阵。

**迭代过程**：在第$k$次迭代中，首先使用当前的统一适配器$\Delta M_{unified}^k$对样本进行推理，提取输入特征$x_{in}^k$。对于输入样本$x$，推理过程可表示为$y^k = (M + \Delta M_{unified}^k)(x)$，其中$y^k$是模型的输出。通过对输出进行分析，得到输入特征$x_{in}^k$。

**更新优化目标**：根据提取的输入特征$x_{in}^k$，更新优化目标函数。优化目标函数旨在最小化合并后的适配器在多个任务上的损失，可表示为$\min_{\Delta M_{unified}} \sum_{i = 1}^n L((M + \Delta M_{unified})(x_{in}^k), y_{T_i})$，其中$L$是损失函数，用于衡量模型输出与任务$T_i$的真实标签$y_{T_i}$之间的差异。

**求解更新**：通过优化算法（如随机梯度下降等）求解优化目标函数，得到更新后的统一适配器$\Delta M_{unified}^{k + 1}$。

**正则化项引入**：为减少对大量样本的需求，IterIS 引入正则化项$\Omega(\Delta M_{unified})$，将优化目标函数修改为$\min_{\Delta M_{unified}} \sum_{i = 1}^n L((M + \Delta M_{unified})(x_{in}^k), y_{T_i}) + \lambda \Omega(\Delta M_{unified})$，其中$\lambda$是正则化系数，用于平衡损失函数和正则化项的权重。通过正则化项，IterIS 仅需 1 - 5% 的未标记样本即可有效训练，降低了样本需求。在实际应用中，正则化项$\Omega(\Delta M_{unified})$可以是$\ell_1$范数、$\ell_2$范数等，例如$\Omega(\Delta M_{unified}) = \|\Delta M_{unified}\|_2^2$，其作用是对适配器参数进行约束，防止过拟合。

**自适应权重**：为平衡优化过程，IterIS 使用自适应权重$\beta_i^k$来调整不同任务在每次迭代中的重要性。优化目标函数进一步修改为$\min_{\Delta M_{unified}} \sum_{i = 1}^n \beta_i^k L((M + \Delta M_{unified})(x_{in}^k), y_{T_i}) + \lambda \Omega(\Delta M_{unified})$。自适应权重的计算通常基于任务的难度、样本数量或模型在该任务上的表现等因素。例如，可以根据任务的损失值来调整权重，损失值越大，权重越高，使得模型在后续迭代中更加关注该任务的优化。
