### 一段话总结

本文聚焦大语言模型（LLMs）的技能组合任务，**提出可通过合并不同的低秩自适应（LoRA）模块来实现**。研究定义了技能组合问题，给出数学应用题、专业手册问答等实际应用场景。**提出 Learnable Concatenation（CAT）这一 LoRA 合并技术**，通过对各技能 LoRA 进行加权平均，在解决数学应用题、构建问答机器人等任务中，**CAT 方法在准确率等指标上优于数据混合和其他线性合并方法**，且能实现超线性提升。但研究目前局限于两个技能的组合，未来可探索扩展到更多技能的合并方法。

### 详细总结

**研究背景与问题**

**工业应用需求**：在工业场景中，如公司设计产品问答机器人，直接使用通用 LLM 效果不佳，收集特定数据微调成本高，数据混合方法存在灾难性遗忘问题。

**现有研究不足**：自然语言任务中，LoRA 合并用于技能组合的研究较少，以往多任务学习场景下的合并方法在技能组合任务上效果不明。

**技能组合任务与方法**

**任务示例**



| 任务       | 技能组合        | 测试数据集                    | 评估指标             |
| -------- | ----------- | ------------------------ | ---------------- |
| 数学应用题    | 数学、代码       | GSM-Hard                 | 执行准确率            |
| 手册问答     | 专业知识、问答能力   | 开源书籍 / 手册                | 准确率（GPT-4 评估）    |
| 技术文档阅读理解 | 生物医学知识、问答能力 | BioASQ-QA                | Elo 评分（GPT-4 评估） |
| 提示鲁棒性    | 不同提示格式数据集   | SuperNaturalInstructions | 准确率              |

**合并方法**

**数据混合（DATA-MIX）**：在数据集拼接上微调单个模型，成本高，添加新技能需重新训练。

**LoRA 连接**：线性组合 LoRA 更新。如**Learnable concatenation（CAT）**，层 wise 学习权重；MoE 的合并系数依赖输入。

**线性合并 LoRAs**：线性组合 LoRA 参数，如 TIES、DARE 先对参数预处理再合并，LoRA Hub 从少量示例学习权重。

**实验设计与设置**

**模型与参数**：以 Llama-7b 为基础模型，LoRA 秩设为 32，alpha 为 64，dropout 为 0.05，目标模块包括 {"q\_proj", "v\_proj", "k\_proj", "up\_proj", "down\_proj"} 。

**数据与训练**：不同任务使用相应数据集，如数学应用题用 MetaMathQA 和 Code-Alpaca。各方法训练细节不同，如 CAT 在小部分数据上训练合并系数 1 轮，学习率 1e−4 。

**实验结果与分析**

**任务表现**：在解决 GSM-Hard 数学应用题时，CAT 准确率达 21.11%，超线性提升显著；在手册问答和技术文档阅读理解任务中，CAT 也优于多数方法。在提示鲁棒性实验中，CAT 在部分格式组合下表现良好。

**消融实验**：学习权重的 CAT 在 GSM-Hard 实验和 QAbot 实验中，比静态权重（$\alpha_{1}^{l}$ , $\alpha_{2}^{l}=0.5$ ）的 CAT 表现更好，证明学习权重对性能提升有重要作用。

**研究局限与展望**

**现有局限**：目前研究局限于两个技能的组合，在多技能（如 3 个提示格式）场景下，LoRA 合并基线方法不如 DATA-MIX。

**未来方向**：设计能有效组合更多技能的合并方法，为大规模模型训练提供替代方案。

### 关键问题

**CAT 方法相较于其他 LoRA 合并方法的优势是什么？**

**答案**：CAT 方法通过层 wise 学习合并系数，能更好地适应不同任务需求。在解决数学应用题、手册问答等任务时，准确率更高，例如在 GSM-Hard 数学应用题任务中，CAT 的准确率为 21.11%，优于 TIES、DARE 等方法。同时，它能实现超线性提升，有效利用不同技能 LoRA 的能力解决新问题。

**数据混合方法在技能组合任务中有哪些不足？**

**答案**：数据混合方法在技能组合任务中存在诸多不足。一方面，每当添加新技能时，需要重新训练模型，成本较高。另一方面，该方法可能会出现灾难性遗忘问题，如在训练产品手册问答模型时，可能会丢失之前学到的通用问答能力。此外，在提示鲁棒性实验中，数据混合方法的表现甚至不如单个模型。

**为什么当前研究局限于两个技能的组合？**

**答案**：当前研究局限于两个技能的组合主要有两个原因。一是难以确定需要大量可清晰识别技能的实际场景；二是即便找到这样的场景，LoRA 合并在多技能情况下的有效性也不明确。如在提示鲁棒性实验中，当训练涉及 3 个不同提示格式时，所有 LoRA 合并基线方法的表现都不如 DATA-MIX，这表明多技能场景下 LoRA 合并效果不佳。

# LoRA合并在技能组合任务中的方法与实验详解

## 一、LoRA 合并方法详解

### 1.1 数据混合（DATA-MIX）

数据混合方法是在数据集拼接的基础上对单个模型进行微调。具体操作时，将不同技能对应的数据集整合到一起，然后使用整合后的数据集对模型进行训练。这种方法看似直接，但存在明显缺陷。例如，在公司设计产品问答机器人时，若要添加新的产品知识技能，就需要重新收集、整理相关数据，并重新训练整个模型，成本极高。而且，在训练过程中，新数据可能会覆盖模型之前学到的知识，导致灾难性遗忘问题。比如在训练产品手册问答模型时，可能会丢失之前学到的通用问答能力，使得模型在处理非产品相关问题时表现变差 。

### 1.2 LoRA 连接

LoRA 连接的核心思路是对 LoRA 更新进行线性组合，其中 Learnable Concatenation（CAT）是一种典型方法。CAT 通过层 wise 学习权重，对各技能 LoRA 进行加权平均。具体而言，在模型的每一层，CAT 会根据训练数据学习一个权重系数，用于权衡不同技能 LoRA 对该层输出的贡献。这种方式能够更灵活地适应不同任务需求，因为不同任务在不同层对技能的依赖程度可能不同。例如在处理数学应用题时，某些层可能更依赖数学知识的 LoRA，而另一些层则可能更依赖代码生成的 LoRA，CAT 的层 wise 权重学习机制可以很好地捕捉这种差异 。相比之下，MoE（Mixture of Experts）的合并系数依赖输入，灵活性相对较差，难以针对不同层的特性进行优化。

### 1.3 线性合并 LoRAs

线性合并 LoRAs 是将 LoRA 参数进行线性组合。像 TIES、DARE 等方法，会先对参数进行预处理，例如对参数进行归一化、特征提取等操作，然后再进行合并。而 LoRA Hub 则是从少量示例中学习权重，通过对少量具有代表性的示例数据进行分析，确定不同 LoRA 参数的权重，从而实现合并。这些方法虽然也能实现 LoRA 的合并，但在适应性和效果上，相较于 CAT 方法存在一定差距。

## 二、实验设计与结果分析

### 2.1 实验设计

**模型与参数**：实验以 Llama-7b 作为基础模型，LoRA 秩设定为 32，alpha 为 64，dropout 为 0.05，目标模块选定为 {"q\_proj", "v\_proj", "k\_proj", "up\_proj", "down\_proj"}。这样的参数设置是在综合考虑模型性能和计算资源的基础上确定的，能够在保证一定精度的同时，降低计算成本。

**数据与训练**：针对不同任务使用相应的数据集。在数学应用题任务中，采用 MetaMathQA 和 Code-Alpaca 数据集；手册问答任务使用开源书籍 / 手册数据；技术文档阅读理解任务使用 BioASQ-QA 数据集；提示鲁棒性实验使用 SuperNaturalInstructions 数据集。不同方法的训练细节各有不同，以 CAT 方法为例，它在小部分数据上训练合并系数 1 轮，学习率设为 1e−4。这种训练方式能够快速学习到合适的权重系数，同时避免过拟合。

### 2.2 实验结果

**任务表现**：在解决 GSM-Hard 数学应用题时，CAT 方法的准确率达到了 21.11%，相比其他方法实现了超线性提升。在手册问答和技术文档阅读理解任务中，通过 GPT-4 评估准确率和 Elo 评分，CAT 也优于多数方法。在提示鲁棒性实验中，CAT 在部分格式组合下同样表现良好。这表明 CAT 方法能够有效利用不同技能 LoRA 的能力，解决实际问题，在多种任务场景中都展现出了优异的性能 。

**消融实验**：为探究学习权重对 CAT 性能的影响，进行了消融实验。将学习权重的 CAT 与静态权重（$\alpha_{1}^{l}$ , $\alpha_{2}^{l}=0.5$ ）的 CAT 在 GSM-Hard 实验和 QAbot 实验中进行对比，结果显示学习权重的 CAT 表现更好。这充分证明了学习权重机制对性能提升的重要作用，它能够使 CAT 方法根据任务需求动态调整不同 LoRA 的权重，从而提高模型的适应性和准确性 。
