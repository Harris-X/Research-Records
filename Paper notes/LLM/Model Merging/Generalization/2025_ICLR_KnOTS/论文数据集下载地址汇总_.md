# **《MODEL MERGING WITH SVD TO TIE THE KNOTS》论文中所用实验数据集的下载资源汇总**

## **引言**

本报告旨在对学术论文《MODEL MERGING WITH SVD TO TIE THE KNOTS》(arXiv:2410.19735v1) 1 中所使用的各实验数据集的下载地址及获取方式进行系统性汇总。该论文在其研究中广泛采用了计算机视觉与自然语言处理领域的多个基准数据集，以验证其模型合并方法的有效性。为方便后续研究者复现实验结果或在相似数据集上开展新的研究工作，本报告将详细梳理各数据集的官方出处、推荐下载链接以及其他获取途径，并结合当前数据集管理的普遍实践，提供相关的背景信息与分析。

## **I. 计算机视觉数据集下载信息**

本章节详细列出了论文 1 中用于计算机视觉实验的八个主要数据集的下载信息。这些数据集覆盖了细粒度分类、纹理识别、遥感影像分类、交通标志识别、手写数字识别及场景理解等多个方面。

### **1\. Cars (Stanford Cars Dataset) (Krause et al., 2013\)**

* **论文引用:** Krause et al., 2013 1。  
* **官方项目页面:** https://ai.stanford.edu/\~jkrause/cars/car\_dataset.html 2。  
  * **背景与分析:** 此页面是斯坦福大学发布的 Cars 数据集的原始官方来源。然而，直接访问此原始页面有时可能存在不稳定性或内容更新不及时的情况 4。  
* **下载/访问说明:**  
  * **Hugging Face (推荐):** 可通过 Hugging Face Hub 上的 tanganke/stanford\_cars 进行访问 5。使用 datasets 库加载指令为：load\_dataset("tanganke/stanford\_cars")。  
    * **背景与分析** 5**:** Hugging Face 提供了便捷的编程接口和预处理版本，是目前推荐的获取方式之一。tanganke/stanford\_cars 不仅包含原始的训练集和测试集，还提供了多种噪声和变换下的版本，便于鲁棒性研究。  
  * **Meta-Album:** Meta-Album 项目也收录了此数据集，并提供了不同规模子集的 OpenML 下载链接 2。例如，Micro 版本的 OpenML ID 为 44245。  
    * **背景与分析** 2**:** Meta-Album 为元学习研究提供了标准化的数据集版本，其 OpenML 链接为研究者提供了另一种可靠的获取途径。  
  * **官方页面直接链接 (可能不稳定):** 原始官方页面曾提供直接下载链接，但目前更推荐通过上述聚合平台获取。  
* **数据集简述:** 包含16,185张分属于196个类别的汽车图像，主要用于细粒度图像分类任务 2。  
* **数据获取方式的演变:** Cars 数据集的获取方式体现了研究数据共享的演进。最初依赖于大学项目页面的直接下载，这种方式虽然直接，但长期维护性和可访问性可能面临挑战。如今，如 Hugging Face 和 OpenML (通过 Meta-Album) 这样的第三方平台，通过提供版本化、易于编程访问的数据集副本，极大地提升了数据集的可获取性和研究的可复现性。这些平台通常还提供数据预处理、数据增强版本，进一步方便了研究者。
* https://github.com/jhpohovey/StanfordCars-Dataset

## **II. 自然语言处理 (NLP) 数据集下载信息**

本章节汇总了论文 1 中用于自然语言处理实验的六个数据集的下载信息。其中许多数据集是 GLUE (General Language Understanding Evaluation) 基准测试的一部分。

* **GLUE 数据集 (MNLI, QNLI, RTE) 的通用获取方式:**  
  * 尽管这些数据集可能有其独立的原始项目页面，但作为 GLUE 基准的一部分，它们通常通过程序化方式获取更为便捷。官方的 GLUE 下载脚本 (download\_glue\_data.py 38) 提供了许多任务的直接 dl.fbaipublicfiles.com 下载链接。然而，Hugging Face (nyu-mll/glue 40) 提供了更为通用和主流的访问方法，例如 load\_dataset("nyu-mll/glue", "task\_name")。GLUE 官方网站本身 46 可能因 JavaScript 依赖而不易于直接下载。  
  * 这种转变反映了研究数据共享的趋势：对于像 GLUE 这样的基准测试套件，通过社区标准库（如 Hugging Face datasets）进行程序化访问，在很大程度上取代了从项目网站手动下载或使用特定脚本的方式。这简化了数据获取并将其集成到研究工作流程中。

### **1\. SNLI (Stanford Natural Language Inference) (Bowman et al., 2015\)**

* **论文引用:** Bowman et al., 2015 1。  
* **官方项目页面:** https://nlp.stanford.edu/projects/snli/ 47。  
  * **背景与分析:** 这是 SNLI 的斯坦福大学官方主页，包含数据集信息、论文引用和直接下载链接。  
* **下载/访问说明:**  
  * **官方直接下载 (推荐):** https://nlp.stanford.edu/projects/snli/snli\_1.0.zip (约 100MB) 47。  
    * **背景与分析** 48**:** 这是版本 1.0 的清晰官方下载链接。  
  * **Hugging Face:** 可通过 load\_dataset('snli') 加载 47。  
* **数据集简述:** 包含57万对由人工编写的英文句子对，用于自然语言推断任务 48。GLUE 下载脚本 38 明确指出其不再下载 SNLI，需要手动下载，这与 SNLI 拥有独立的斯坦福页面和下载方式相符。  
* **独立分发策略:** SNLI 尽管与 GLUE 中的任务密切相关（例如 MNLI 是在其基础上建模的 50），但它通过斯坦福 NLP 页面 48 维持着自己独特的分发渠道。GLUE 下载脚本明确排除 SNLI 38 也强化了这一点。这表明，即使在相关数据集领域（如自然语言推断），访问方法也可能不同，不能假设所有相关数据集都遵循单一的分发模式。

### **2\. MNLI (Multi-Genre Natural Language Inference) (Williams et al., 2018\)**

* **论文引用:** Williams et al., 2018 1。

## **III. 关于数据集访问的通用说明与总结**

对上述数据集的下载信息进行梳理后，可以观察到当前科研数据共享与获取方面的一些普遍趋势和注意事项：

* **中心化平台的主导地位:** 一个显著的趋势是，越来越多的基准数据集可以通过像 Hugging Face Datasets 这样的中心化平台获取。这极大地简化了访问过程，通常只需一行 Python 代码（例如 load\_dataset()）即可加载数据集 5。这与以往依赖各个大学或项目网站的传统方式形成对比，后者更容易出现链接失效的问题。  
* **链接失效的挑战:** 一些在早期资料或甚至主要数据集页面中提及的官方项目页面或直接下载链接，经查证已无法访问（例如 Cars 4，DTD 9，RESISC45 的一个备用链接 30）。这突显了长期数据存档面临的挑战，以及持久化标识符（如 Zenodo 常用的 DOI）和社区镜像的重要性。  
* **多样化的访问机制:**  
  * **直接下载:** 一些数据集仍提供直接的 .zip 或 .tar.gz 下载方式 (例如 SUN397 31, SVHN 35, SNLI 48)。  
  * **基于库的访问:** 许多数据集最好通过 Hugging Face datasets、TensorFlow Datasets、PyTorch Vision 等库，或 FiftyOne 8 这样的专用库来访问。  
  * **下载脚本:** 部分数据集提供 shell 脚本用于下载 (例如 SciTail 63, GLUE 38)。  
* **数据集版本与格式:** 用户应注意数据集可能存在多个版本或格式 (例如 SVHN 的完整图像与裁剪数字版 35；EuroSAT 的 RGB 与多光谱版 12)。原始论文 1 未必总是详述这些细节，因此研究人员可能需要推断或测试常用版本。  
* **官方文档的重要性:** 即使下载源自聚合平台，也建议尽可能查阅原始数据集论文或官方文档，以了解数据收集、标注和预期用途。  
* **许可协议:** 本报告主要关注下载访问，但用户务必在使用前检查每个数据集的许可协议，确保其预期用途符合条款。多个资料片段中提及了许可信息 (例如 Cars 2, RESISC45 25, SNLI 48)。  
* **科研数据共享的演进趋势:** 获取数据集的方法正在不断发展。传统大学网页曾是主要途径，但随着 Hugging Face、Zenodo、Kaggle 等平台的兴起，以及通过库进行的程序化访问，研究人员发现、下载和集成数据的方式正在改变。这种转变通常有利于易用性、可复现性（当版本管理良好时）以及对抗单个服务器故障或链接失效的韧性。然而，这也引入了对这些第三方平台的依赖。

希望本报告能为相关研究人员提供清晰、准确的数据集获取指引。
