# 《AdaMMS：一种有效的异构多模态大语言模型合并方法》

\*

***

**一段话总结**：本文提出了 AdaMMS 这一针对异构多模态大语言模型（MLLMs）的新型模型合并方法。它通过**映射、合并和搜索**三个步骤，解决了异构 MLLMs 合并时架构差异和参数空间不对称的问题。在映射步骤定义映射函数对齐参数；合并步骤使用线性插值优化性能；搜索步骤通过无监督超参数选择方法确定插值系数。实验表明，AdaMMS 在多模态任务基准测试中优于先前方法，且无监督超参数选择方法能有效选择接近最优的系数，仅需 100 个无标签数据样本。

**详细总结**

**研究背景**：模型合并在大语言模型（LLMs）领域应用广泛，但在多模态大语言模型（MLLMs）中未得到广泛采用，主要原因是 MLLMs 的异构性，包括语言模型架构修改、模态特定编码器和分词器的差异等，使得直接应用模型合并方法面临挑战。

**相关工作**

**模型合并**：现有模型合并方法分为合并同质模型和异构模型两类。同质模型合并方法如 Task Arithmetic、Ties - Merging 等，无法直接应用于架构不同的模型；异构模型合并方法如 FuseLLM、FuseChat 等，虽探索了融合异构 LLMs 的能力，但依赖监督式持续训练，需要大量标注数据和计算资源。

**多模态大语言模型**：MLLMs 在 LLMs 基础上增加了多模态处理能力，但不同 MLLMs 在架构上存在差异，分为基于不同预训练语言模型和同一预训练语言模型但有不同修改两个层次，本文主要解决第二个层次的架构差异问题。

**AdaMMS 方法**：提出 AdaMMS（自适应映射、合并和搜索）方法，包含三个步骤。

**映射**：定义映射函数$f$，将不同架构模型的参数进行对齐。对于共享权重直接映射，对于额外权重，若为重复的多模态参数则映射到对应权重，否则映射为$\phi$。

**合并**：借鉴 Task Arithmetic 范式，对任务向量进行合并操作，并应用线性插值。任务向量$\tau_{i}=\theta_{i}-\theta_{0}$，合并公式为$\theta_{out }=\theta_{0}+(1-\alpha) \tau_{1}+\alpha \tau_{2}$（等价于$\theta_{out }=(1-\alpha) \theta_{1}+\alpha \theta_{2}$），根据映射函数$f$对异构 MLLMs 进行合并操作。

**搜索**：提出无监督超参数选择方法，通过生成响应差异估计模型性能，选择差异最小的$\alpha$作为近似最优解。理论上，模型性能在最优解附近更稳定，且实验证明该方法在小数据子集上也能有效选择超参数。

**实验设置**

**基线模型**：选取 Task Arithmetic、Ties - Merging、DARE（包括 Dare - Linear 和 Dare - Ties）、MetaGPT 等模型合并方法作为基线。

**实验模型**：主要在基于 Qwen2 和 LLaMA 架构的 MLLMs 组合上进行实验，如将 LLaVA - OneVision - Qwen - 7B 合并到 Qwen2 - VL7B，将 LLaVAv1.5 - 7B 合并到 CogVLM - Chat - 7B 等。

**评估基准**：使用涵盖多种视觉语言能力的基准测试，包括综合评估（MME、SeedBench、VizWiz）、认知与推理（MMMU、OK - VQA、GQA）、文本丰富的 VQA（OCRBench、TextVQA）三类。

**实验结果**

**总体性能**：在不同 MLLM 对的合并实验中，**AdaMMS 在大多数任务上取得了最高的累积性能得分**。例如，在将 LLaVA - OneVision - 7B 合并到 Qwen2 - VL - 7B 的实验中，AdaMMS 的 SUM 得分达到 563.56，比基线方法高；在将 LLaVA - v1.5 - 7B 合并到 CogVLM - Chat - 7B 的实验中，AdaMMS 的 SUM 得分达到 459.21，同样优于基线方法。

**超参数选择**：**无监督超参数选择方法能有效选择接近最优的**** ****值**。如在将 LLaVA - OneVision - 7B 合并到 Qwen2 - VL - 7B 的实验中，AdaMMS 选择的$\alpha$值与理论最优值的最大偏差仅为 0.5 点。

**结论**：AdaMMS 成功解决了异构 MLLMs 合并的挑战，在多模态任务基准测试中优于现有模型合并方法，且无监督超参数选择方法仅需 100 个数据样本就能有效搜索接近最优的系数，为未来无监督性能估计和优化研究提供了有价值的见解。

**关键问题**

**问题 1：AdaMMS 的映射步骤如何处理不同模型间的参数差异？**

**答案**：AdaMMS 在映射步骤中，对于模型间的共享权重，直接进行映射；对于额外权重，如果是模型特定设计中的重复多模态参数，则映射到其在另一模型中的原始对应权重，否则映射为$\phi$，在合并时不进行操作，以此方式处理不同模型间的参数差异。

**问题 2：与其他模型合并方法相比，AdaMMS 的优势主要体现在哪些方面？**

**答案**：与其他方法相比，AdaMMS 的优势在于能处理异构 MLLMs 的合并，通过独特的映射、合并和搜索步骤，无需额外训练和标注数据。在实验中，**AdaMMS 在多种视觉语言基准测试中总体性能更优**，其无监督超参数选择方法能有效选择接近最优的系数，且在小数据子集上也能保持良好性能。

**问题 3：AdaMMS 的无监督超参数选择方法的理论依据是什么？**

**答案**：AdaMMS 无监督超参数选择方法的理论依据是模型性能与生成一致性相关。在参数空间中，假设在给定任务的子空间内，模型性能的变化趋势是凸的，在最优解附近，模型响应更稳定。通过生成响应差异来估计模型性能，选择差异最小的超参数$\alpha$，可近似得到最优的$\alpha$值，从而优化模型性能。



# 《AdaMMS：异构多模态大语言模型的高效合并方法》

论文提出的 AdaMMS 方法针对异构多模态大语言模型（MLLMs）的合并问题，通过 \*\* 映射（Mapping）、合并（Merging）、搜索（Searching）\*\* 三个核心步骤解决架构差异、参数空间不对称和无监督超参数优化问题。以下是方法的详细解析，包括公式和符号的含义：

### **1. 映射步骤（Mapping）**

#### **目标**

将异构模型 $M_1$ 和 $M_2$ 的参数对齐，解决架构差异（如 Transformer 块数量、模态编码器不同）。

#### **符号定义**

$\Theta_1 = \{\theta_1^i\}$：模型 $M_1$ 的参数集合，$\theta_1^i$ 表示第 $i$ 个参数。

$\Theta_2 = \{\theta_2^j\}$：模型 $M_2$ 的参数集合。

映射函数 $f$：将 $M_1$ 的参数 $\theta_1^i$ 映射到 $M_2$ 中的对应参数 $f(\theta_1^i)$，若无对应参数则映射为 $\phi$（无操作）。

#### **映射原则**

**共享权重**：来自相同预训练模型的权重直接映射（如语言模型的基础层）。

**额外权重**：因架构修改引入的权重（如 MLLM 的视觉专家模块），若 $M_2$ 有对应结构则映射，否则保留 $M_1$ 的原始参数。

### **2. 合并步骤（Merging）**

#### **目标**

通过线性插值合并映射后的参数，自适应调整模型在不同任务上的性能倾向。

#### **符号定义**

**任务向量**：$\tau_i = \theta_i - \theta_0$，其中 $\theta_i$ 是微调后参数，$\theta_0$ 是共享的预训练初始参数（如未微调的基础模型权重）。

插值系数 $\alpha \in [0, 1]$：控制 $M_1$ 和 $M_2$ 的权重比例，$\alpha=0$ 表示完全保留 $M_1$，$\alpha=1$ 表示完全保留 $M_2$。

#### **合并公式**

**任务向量线性插值**（等价于参数直接插值）：

$ 
   \theta_{\text{out}} = \theta_0 + (1-\alpha)\tau_1 + \alpha\tau_2 = (1-\alpha)\theta_1 + \alpha\theta_2
    $

其中，$\theta_{\text{out}}$ 是合并后的参数。

**异构参数处理**：对每个参数 $\theta_1^i$ in $M_1$，合并规则为：

$$
\theta_{\text{out}}^i =    \begin{cases}    \theta_1^i, & \text{if } f(\theta_1^i) = \phi \ (\text{无对应参数}) \\   (1-\alpha)\theta_1^i + \alpha f(\theta_1^i), & \text{otherwise} \ (\text{存在对应参数，线性插值})   \end{cases}  
$$


合并函数表示为：

$ 
   \text{Merge}(\Theta_1, \Theta_2; f; \alpha) = \{\theta_{\text{out}}^i\}
    $

### **3. 搜索步骤（Searching）**

#### **目标**

无监督选择最优插值系数 $\alpha$，利用生成响应的一致性估计模型性能。

#### **核心假设**

模型性能与生成响应的稳定性正相关：最优 $\alpha$ 处，相邻 $\alpha$ 生成的响应差异最小（一致性最高）。

#### **符号定义**

$G(\alpha)$：合并模型在输入子集 $\bar{t}$ 上的生成响应集合。

$D_t(\alpha; \alpha^-, \alpha^+)$：当前 $\alpha$ 与相邻候选 $\alpha^-$、$\alpha^+$ 的响应差异，使用 Exact Match 或句子嵌入余弦相似度计算。

#### **优化目标**

寻找使响应差异最小的 $\alpha$，近似最大化模型性能：

$ 
\bar{\alpha} = \underset{\alpha}{\text{argmin}} \left( D_{\bar{t}}(\alpha; \alpha^-, \alpha^+) \right)
 $

其中，$\bar{t}$ 是无标签的小样本子集（如 100 个输入），$D_{\bar{t}}$ 计算子集上的平均响应差异。

#### **理论支持**

假设性能曲面局部凸，最优参数 $\Theta^*$ 处梯度为零，二阶导数半正定，响应变化平缓：

$ 
S_{t_i}(\Theta) \approx S_{t_i}(\Theta^*) + \frac{1}{2}(\Theta - \Theta^*)^\top H(\Theta^*)(\Theta - \Theta^*)
 $

其中 $H(\Theta^*)$ 是 Hessian 矩阵，正定性保证了局部稳定性。

### **关键公式总结**

| 符号 / 公式                                                  | 含义                                                         |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| $\tau_i = \theta_i - \theta_0$                               | 任务向量：微调参数与预训练参数的差值，表征模型对特定任务的适应 |
| $\theta_{\text{out}} = (1-\alpha)\theta_1 + \alpha\theta_2$  | 线性插值合并参数，$\alpha$ 控制 $M_1$ 和 $M_2$ 的权重比例    |
| $\theta_{\text{out}}^i = \theta_1^i$（若 $f(\theta_1^i)=\phi$） | 无对应参数时保留 $M_1$ 的原始参数                            |
| $\bar{\alpha} = \underset{\alpha}{\text{argmin}} D(\alpha)$  | 无监督搜索最优 $\alpha$，基于响应差异最小化                  |

### **方法流程**

**映射**：通过 $f$ 对齐 $M_1$ 和 $M_2$ 的参数，处理架构差异。

**合并**：对映射后的参数进行线性插值，生成候选合并模型（不同 $\alpha$）。

**搜索**：在无标签数据上计算各 $\alpha$ 的响应差异，选择差异最小的 $\alpha$ 作为最优解。

### **创新点**

**异构参数映射**：首次支持不同架构 MLLMs 的合并，通过结构对齐避免参数不匹配。

**无监督超参数优化**：利用响应一致性替代监督信号，无需标注数据即可选择最优 $\alpha$，大幅降低计算成本。

**理论支撑**：通过凸性假设证明响应稳定性与性能的正相关性，为无监督搜索提供理论依据。

通过以上步骤，AdaMMS 在无需额外训练的情况下，有效合并异构 MLLMs，提升多模态任务性能，尤其在无标签场景下表现优异。
