### 一、 当前相关工作的研究进展

模型融合（Model Merging）旨在将多个针对特定领域微调的专家模型合并为一个全能模型，且无需额外的训练数据，从而大幅降低存储和部署成本 。当前的研究主要分为以下几个方向 ：

+1

- **动态融合（MoE-like）**：根据输入动态加载特定任务模块，但会增加存储和计算开销 。
    
    +1
    
- **静态无数据融合（Static Data-free Merging）**（本文的重点）：
    
    - **线性插值法**：如 Task Arithmetic 和 Weight Averaging，直接对参数进行加减，简单但容易产生参数冲突 。
        
    - **稀疏化方法**：如 TIES 和 DARE，通过丢弃冗余参数和重新缩放来减少干扰 。
        
    - **基于 SVD 的方法**：如 TSV 和 Iso-C，利用奇异值分解提取任务向量的低秩特征以减少正交干扰 。
        
    - **基于优化的方法**：如 WUDI Merging，将模型融合转化为一个无数据的参数优化问题 。
        

**目前的瓶颈**：尽管上述方法在纯文本 LLM 或视觉分类任务上取得了一定成果，但针对 **多模态大语言模型（MLLMs）** 的融合缺乏统一的基准测试 。此外，像 WUDI 这样的优化方法在面对复杂的多模态任务向量时，极易陷入优化不稳定或导致模型基础语言能力崩溃的困境 。

+2

### 二、 动机与方法流程：从 WUDI 到 OptMerge

为了讲清楚 OptMerge，我们需要先理解它的“前身” WUDI Merging 的原理及其缺陷。

#### 1. 前置概念与 WUDI 的局限性

模型融合的核心在于处理 **任务向量（Task Vector）**，即微调模型参数与基础模型参数的差值 $\tau_i = \theta_i - \theta_0$ 。WUDI Merging 证明了任务向量构成了微调数据的一个近似线性子空间 。因此，它提出通过最小化融合向量 $\tau_{m,l}$ 与各个任务向量 $\tau_{i,l}$ 之间的“干扰”来进行优化 。

+2

**动机（问题所在）**：

- **对于全量微调（Full Fine-Tuning）模型**：直接加和或优化任务向量会引入极大的冗余和噪声（不同任务可能重复学习了相同的基础能力，或者包含了非本质的参数更新） 。
    
- **对于 LoRA 微调模型**：LoRA 的参数更新具有极度的低秩稀疏性。如果直接用 Adam 优化器去优化融合向量，为了在不同任务方向上“强行”满足正交性，优化器会“走捷径”，导致融合向量的范数（即参数的绝对绝对值）急剧膨胀 。这种膨胀一旦加回基础模型，就会破坏其原有的参数分布，导致模型能力崩溃 。
    
    +2
    

#### 2. OptMerge 的核心流程 基于上述痛点，OptMerge 针对两种微调范式设计了不同的降噪和优化流程。

**针对全量微调（Full Fine-Tuning）**：

1. **计算中心化均值**：求出所有任务向量的平均值 $\overline{\tau}_l$，并将各个任务向量去中心化 。
    
2. **SVD 降噪**：对去中心化后的任务向量进行奇异值分解，剥离冗余噪声，只保留最核心的 $k$ 个主成分 。
    
    +1
    
3. **梯度下降优化**：用降噪后的特征子空间替代原始任务向量，作为优化的目标空间 。
    

**针对 LoRA 微调**：

1. **直接 SVD 降秩**：由于 LoRA 本身已经是低秩的，直接对其进行 SVD 截断（不去中心化），直接丢弃尾部能量，压缩范数 。
    
2. **切换优化器**：放弃 Adam，改用 SGD（随机梯度下降）。SGD 具有隐式正则化效果，能更好地在稀疏梯度下保持稳定，防止向量范数爆炸 。
    
3. **均值初始化**：将融合向量初始化为各任务向量的均值，进一步抑制参数膨胀 。

### 三、 具体公式与符号含义

以下是上述逻辑的严格数学表达。

**基础符号定义**：

- $n$: 参与融合的微调专家模型数量。
    
- $\tau_{i,l}$: 第 $i$ 个任务模型在第 $l$ 层的任务向量（即 $\theta_{i,l} - \theta_{0,l}$）。
    
- $\tau_{m,l}$: 我们需要求解（优化）的最终融合向量（在第 $l$ 层）。
    
- $\overline{\tau}_l$: 第 $l$ 层所有任务向量的平均值，即 $\frac{1}{n}\sum_{i=1}^n \tau_{i,l}$ 。
    
- $||\cdot||_F^2$: Frobenius 范数的平方。
    

1. 基础 WUDI 优化目标 ：

$$\min_{\tau_{m,l}} \mathcal{L}_l = \sum_{i=1}^n \frac{1}{||\tau_{i,l}||_F^2} ||(\tau_{m,l} - \tau_{i,l})(\tau_{i,l})^\top||_F^2$$

_(含义：寻找一个 $\tau_{m,l}$，使得它在各个任务向量 $\tau_{i,l}$ 的转置空间上的投影，尽可能接近原始任务向量本身的投影。)_

2. OptMerge 全量微调优化目标 ： 首先进行 SVD 分解：

+1

$$SVD(\tau_{i,l} - \overline{\tau}_l) = U \Sigma V^\top$$

截断取前 $k$ 个主成分，记作 $U_{1:k}, \Sigma_{1:k}, V_{1:k}^\top$。然后将 WUDI 公式中的原始任务向量替换为降噪后的低秩近似：

$$\min_{\tau_{m,l}} \mathcal{L}_l = \sum_{i=1}^n \frac{1}{||\tau_{i,l}||_F^2} ||(\tau_{m,l} - U_{1:k}\Sigma_{1:k}V_{1:k}^\top - \overline{\tau}_l)(\Sigma_{1:k}V_{1:k}^\top)^\top||_F^2$$

_(含义：利用 SVD 滤除了高频噪声后，只在最重要的 $k$ 个特征维度上对齐融合向量和专家向量，从而大幅减少了不同任务间的相互干扰。)_

### 四、 具体案例演示

假设你是一家 AI 公司的工程师，你们基于基础模型 **Qwen2-VL-7B-Base**，使用 LoRA 技术分别训练了三个不同领域的专家模型：

1. **模型 A**：专注于 VQA（视觉问答）。
    
2. **模型 B**：专注于 Geometry（几何数学推理）。
    
3. **模型 C**：专注于 Chart（图表理解）。
    

**传统做法（混合训练 Mixture Training）**： 你需要把 VQA、几何、图表的所有数据集混在一起，重新从头训练一遍 Qwen2-VL。耗时几十个小时，且需要耗费几百 GB 的显存（如论文中 Table 7 所示，需 256GB 显存，耗时 24.56 小时） 。

+1

**使用 OptMerge 的做法**：

无需触碰原始数据。

1. **提取差异**：把模型 A、B、C 的权重分别减去基础模型权重，得到三个 LoRA 任务向量 $\tau_A, \tau_B, \tau_C$。
    
2. **SVD 截断**：对 $\tau_A, \tau_B, \tau_C$ 分别进行奇异值分解，砍掉那些微小的、代表噪声的奇异值及对应向量。
    
3. **均值初始化与 SGD 优化**：设定一个初始融合向量 $\tau_m = (\tau_A + \tau_B + \tau_C) / 3$。然后使用 SGD 优化器，在损失函数（上述公式）的指导下，迭代 300 次微调 $\tau_m$ 的数值。
    
4. **最终融合**：将优化好的 $\tau_m$ 加回 Qwen2-VL-7B-Base。
    

**结果**：你只用了单卡 21.97GB 显存，花了 3.78 小时 ，就得到了一个既能做几何题、又能看懂图表的“全能”大模型，且其在各项基准测试上的平均表现甚至超越了把数据混在一起重新训练的模型 。

+1
