# LoRA-LEGO方法与实验介绍

在 “MERGING LORAS LIKE PLAYING LEGO: PUSHING THE MODULARITY OF LORA TO EXTREMES THROUGH RANK-WISE CLUSTERING” 论文中，作者提出了 LoRA - LEGO 框架来解决低秩自适应（LoRA）合并中的参数干扰问题，提高合并后 LoRA 的性能。下面将详细介绍该方法、相关公式符号，并给出案例。

**方法核心概念**

**最小语义单元（MSU）**：LoRA 模块中，将下投影矩阵$A$的每一行与上投影矩阵$B$的对应列视为一个整体，定义为最小语义单元$ s_{i}=[a_{i}, b_{i}]$，$a_{i}$是$A$的第$i$行，$b_{i}$是$B^{T}$的第$i$行 。每个 MSU 对应 LoRA 的一个秩，封装独特语义信息。

**排列不变性**：对 LoRA 模块，若用置换矩阵$P$（$P^{T}P = I$，$I$为单位矩阵）置换$A$的行得到$A' = PA$，并相应置换$B$的列得到$B' = BP^{T}$，则$BA = B'A'$。这意味着 LoRA 内 MSU 排列顺序改变不影响输出。

**拼接求和等价性**：对于两个秩为$r$的 LoRAs $ (A_{1}, B_{1})$和$(A_{2}, B_{2})$ ，定义拼接矩阵$A'=\begin{bmatrix}A_{1}\\A_{2}\end{bmatrix}$ ，$B'=\begin{bmatrix}B_{1}&B_{2}\end{bmatrix}$ ，则拼接模型输出向量$y = B'A'x=(B_{1}A_{1}+B_{2}A_{2})x$ ，即拼接后 LoRA 输出等价于各单独 LoRA 输出之和。

**LoRA - LEGO 框架**

**MSU 分组**：合并$p$个 LoRAs 时，先将每个 LoRA 分解为多个 MSUs。设$ {A_{i}, B_{i}}_{i = 1}^{p}$表示$p$个秩为$r_{i}$的 LoRA 层参数，每个$A_{j}$ ，$B_{j}$模块含$r_{j}$个 MSUs，记为$ {s_{j1}, s_{j2}, ..., s_{jr_{j}}}$ ，其中$s_{jl}=[a_{jl}, b_{jl}]$ ，$a_{jl}=A_{j}[:, l]$ ，$b_{jl}=B_{j}[l, :]^{T}$ 。将所有待合并 LoRAs 的 MSUs 放入 MSU 池$\Phi=\bigcup_{j = 1}^{p}{s_{j1}, s_{j2}, ..., s_{jr_{j}}}$ 。

**MSU 聚类**：利用 K - means 算法对 MSU 池$\Phi$中的 MSUs 按相似性聚类。优化目标为$\underset{\mathbb{C}}{minimize} \sum_{i = 1}^{k} \sum_{s \in \mathbb{C}_{i}}\left\| s-\mu_{i}\right\| ^{2}$ ，其中$\mathbb{C}_{i}$是第$i$个簇，$\mu_{i}$是$\mathbb{C}_{i}$的质心，通过该优化将 MSUs 划分为$k$个簇${\mathbb{C}_{1}, \mathbb{C}_{2}, ..., \mathbb{C}_{k}}$ ，每个 MSU 被分配到距离最近的簇。

**LoRA 重构**：计算每个簇的质心$\mu_{1}, \mu_{2}, ..., \mu_{k}$ ，质心由簇内 MSUs 平均得到，代表簇内广义语义信息。根据 MSU 定义，从质心$\mu_{i}=[a_{i}, b_{i}]$中提取$a_{i}$和$b_{i}$ ，构建新投影矩阵$A'=\begin{bmatrix}a_{1}\\a_{2}\\\vdots\\a_{k}\end{bmatrix}$ ，$B'=\begin{bmatrix}b_{1}^{T}&b_{2}^{T}&\cdots&b_{k}^{T}\end{bmatrix}$ ，得到秩为$k$（$1 ≤ k ≤ \sum_{j = 1}^{p}r_{j}$）的新 LoRA 模型，通过基于相似性对齐 MSUs 解决参数干扰问题。

**合并 LoRA 的最优缩放**

**LoRA 合并后的范数衰减**：合并后参数（簇质心）范数相比合并前簇内参数平均范数会减小。由三角不等式$\left\|\sum_{i = 1}^{p} s_{i}\right\| ≤ \sum_{i = 1}^{p}\left\|s_{i}\right\|$ ，计算质心$\mu=\frac{1}{p} \sum_{i = 1}^{p} s_{i}$时，有$\|\mu\|=\left\|\frac{1}{p} \sum_{i = 1}^{p} s_{i}\right\| \leq \frac{1}{p} \sum_{i = 1}^{p}\left\| s_{i}\right\|$ 。为补偿范数衰减，采用参数重加权，将质心缩放为$\mu'=\frac{\frac{1}{p} \sum_{i = 1}^{p}\left\|s_{i}\right\|}{\|\mu\|} \mu$ ，实现中用无穷范数保证稳定性。

**LoRA 秩增加导致的方差扩展**：随着合并后 LoRA 秩$k$增加，输出方差增大。为归一化输出方差，类似自注意力机制，对合并后 LoRA 输出重加权$\frac{\sqrt{r}}{\sqrt{k}}$ 。定理表明，若$A_{1} \in \mathbb{R}^{p × r}$ ，$B_{1} \in \mathbb{R}^{r × p}$ ，$A_{2} \in \mathbb{R}^{p × k}$ ，$B_{2} \in \mathbb{R}^{k × p}$ ，且矩阵元素独立同分布服从标准正态分布$N(0, 1)$ ，则$Var\left(A_{1} B_{1}\right)=Var\left(\frac{\sqrt{r}}{\sqrt{k}} A_{2} B_{2}\right)$ ，证明过程通过分别计算矩阵元素方差得出。

**方法案例**

**多任务学习场景**：以 Llama2 - {7b, 13b} 为基础模型，训练 7 个 LoRAs 用于不同任务（如 CoLA、MNLI 等） ，合并这些 LoRAs。对比 Weight Averaging、Ensemble 等方法，LoRA - LEGO 在域内（IID）和域外（OOD）任务上均表现更优。例如在 Llama2 - 7b 模型合并实验中，LoRA - LEGO 在平均准确率上达到 62.21，高于 Weight Averaging 的 47.17 等其他方法。同时，LoRA - LEGO 还可用于 LoRA 参数剪枝，保留 33% 参数时能保留 79% 原模型能力，保留 50% 参数时可保留 92% 性能。

**混合任务评估场景**：构建含 48 个任务的 LoRA 池，从每个测试集随机选 50 个样本混合成评估集。采用 LoraRetriever 方法检索与输入样本最相似的前 3 个 LoRAs 进行合并。实验结果显示，LoRA - LEGO 在 IID 和 OOD 场景下均超越其他合并方法（如 Weight Average、Ensemble 等） ，能有效消除参数干扰，充分利用不同 LoRA 能力。

### 实验验证过程与结果

**多任务学习对比实验**

**实验设置**：选用 Llama2 - 7b 和 Llama2 - 13b 模型，在多种多任务场景下对比 LoRA - LEGO 与传统权重平均、集成等方法性能。数据集涵盖多种自然语言处理任务，如 MNLI（Multi - Genre Natural Language Inference，多类型自然语言推理）、QNLI（Question - Natural Language Inference，问题自然语言推理）等。

**实验结果**：从表 3 数据可见，在 IID（独立同分布）和 OOD（分布外）任务中，LoRA - LEGO 表现显著优于基线方法。例如在 Llama2 - 7b 上，权重平均方法平均性能为 47.17，集成方法为 56.84，而 LoRA - LEGO 达到 62.21；Llama2 - 13b 上，LoRA - LEGO 平均性能 70.27，同样远超其他方法。尤其在 MNLI、QNLI 等任务中，LoRA - LEGO 性能提升超 10% ，充分证明其在多任务学习场景中的优势。

**参数剪枝效果实验**

**实验设置**：对模型进行不同比例的参数剪枝操作，观察模型性能变化。通过 LoRA - LEGO 框架的 MSU 聚类机制，保留关键语义单元，对非必要参数进行剪枝。

**实验结果**：从图 6 数据可知，当保留 50% 参数时，模型性能仍能维持 92%；保留 33% 参数时，性能维持 79%。与随机剪枝相比，LoRA - LEGO 基于语义相似性聚类，确保保留的 MSU 是最具代表性的语义单元，展现出高效压缩能力，在大幅减少参数数量的同时，仍能保持较高模型性能。

**异质 LoRA 合并实验**

**实验设置**：尝试合并不同秩的 LoRA，测试 LoRA - LEGO 在处理灵活秩调整场景下的性能，并与集成方法对比。

**实验结果**：在表 5 数据中，LoRA - LEGO 合并不同秩 LoRA 时性能达到 63.39，而集成方法为 62.87，LoRA - LEGO 再次展现出优势，表明其能有效支持异质 LoRA 合并，在实际应用中更具灵活性。



这篇论文主要探讨了 LoRA-LEGO 框架在大语言模型中合并 LoRA 模块的相关内容，在同行评审过程中，评审者指出了一些弱点，作者也针对这些弱点进行了详细回复并优化了论文，以下是具体情况：

1. 论文的弱点
   - **创新性与方法强度问题**：评审者 1z1o 认为该方法依赖简单的 k-means 聚类方法进行分组和聚合，创新性不足，且方法不够强大，导致框架性能受限，如在 WNLI 任务上表现不佳，同时部分基线方法基础且缺乏相关文献引用，影响了比较分析的有效性。
   - **处理高度分歧任务的性能问题**：评审者 9LLA 指出，在合并为高度分歧任务设计的 LoRA 时，性能可能会下降，且合并效果对超参数设置高度敏感。
   - **MSU 与人类可理解语义的关系问题**：评审者 Uiyw 认为 MSU 与人类可理解的语义缺乏关联，尽管方法优于现有方法，但与更广泛的基线方法进行更详细的比较可以加强论点，且未报告该方法可能引入的推理和训练时间、内存等方面的开销。
   - **方法的合理性与扩展性问题**：评审者 YS49 提出，虽然 MSU 是一个有趣的概念，但不清楚为什么对 LoRA 进行更细粒度的合并是组合多个 LoRA 以增强 LLM 能力的正确方法，聚类和簇中心的使用对合并 LoRA 的性能有本质影响，且评估仅使用了 7 个 LoRA，不清楚该方法在更多 LoRA 情况下的工作效果。
2. 作者的回复与优化
   - **针对创新性与方法强度问题的回复**：作者强调工作的核心贡献在于通过 MSUs 对 LoRA 进行进一步模块化，这一方法此前未被认识到，且具有更高的灵活性，能缓解参数干扰，还可用于合并异构 LoRA 和参数修剪。关于 k-means 聚类，作者认为简单有效的方法能增强工作的清晰度、可解释性和可及性，且该方法为 LoRA 带来了创新视角，如可用于终身学习、联邦学习等。同时，作者添加了两个更具代表性的基线方法（DARE 和 DELLA-Merging），并在论文中进行了详细比较和分析（Table 3 和 Appendix H）。
   - **针对处理高度分歧任务的性能问题的回复**：作者表示 LoRA-LEGO 通过聚类 MSUs 确保聚合参数充分对齐，同时灵活选择合并 LoRA 的秩以避免知识冲突。通过在附录 F 中对多种不同任务的实验，以及在附录 G 中对 20 个 LoRA 的大规模合并实验，结果表明在任务多样性高的场景下，LoRA-LEGO 比最佳基线方法有显著提升（分别提升 11% 和 16%），有效解决了合并高度分歧任务 LoRA 的挑战。
   - **针对 MSU 与人类可理解语义的关系问题的回复**：作者通过对 48 个 LoRA 模型的分析，使用 t-SNE 投影可视化 MSUs 的分布，发现同一 LoRA 模型内的 MSUs 更紧密地聚集在一起，相似任务领域的 LoRA 模型的 MSUs 在 t-SNE 空间中更接近，表明 MSUs 确实捕获了有意义的任务相关信息。作者添加了两个基线方法进行更全面的比较，并在多个场景和模型规模上进行评估，结果显示 LoRA-LEGO 始终优于其他方法。同时，作者进行了详细的开销分析，结果表明 LoRA-LEGO 在推理时间和内存消耗上具有竞争力，且准确率显著更高。
   - **针对方法的合理性与扩展性问题的回复**：作者指出传统元素合并方法存在参数未对齐和知识冲突问题，而基于 MSU 的聚类方法通过对齐相似参数和提供足够的参数空间来解决这些问题。在附录 F 的实验中，LoRA-LEGO 在参数干扰更明显的多样任务中表现出色，比 DELLA-Merging 提升 11%。通过在附录 G 中对 20 个 LoRA 的实验，结果表明在大规模合并场景下，LoRA-LEGO 能有效处理参数干扰，比最佳基线方法提升 16%，验证了方法的可扩展性。作者还通过对比 LoRA-LEGO 与选择单个 LoRA 的方法，表明 LoRA-LEGO 在保留和组合模型能力方面更具优势，尤其在 OOD 场景下性能下降更少。
