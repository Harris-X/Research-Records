# 《自适应 LoRA 合并：解决领域增量学习中 LoRA 合并的固定权重问题》

### 一段话总结

本文针对**领域增量学习（DIL）中现有 LoRA 合并算法依赖固定权重、无法动态适应新领域**的问题，提出**自适应 LoRA 合并方法**，通过**动态计算合并系数**（利用 sigmoid 函数和可学习参数）调整各领域适配器的重要性，无需手动选择权重。实验在**PACS 和 OfficeHome 基准**上表明，该方法在**仅需每类 1 个样本**的情况下，性能与最优固定权重方法相当或更优，显著减少超参数调整成本，为 LoRA 适配器在持续学习中的应用提供了新方向。

### 详细总结

#### 1. 研究背景与目标

**问题挑战**：

大模型微调计算成本高，**LoRA**等 PEFT 方法通过更新少量低秩矩阵高效适配任务，但传统方法依赖固定数据分布，无法应对 \*\* 领域增量学习（DIL）\*\* 中动态变化的领域序列。

现有合并算法（如 DARE、TIES-MERGE）依赖**固定权重**，假设任务重要性均等，难以适应 DIL 中领域重要性的动态变化，且需手动调参。

**目标**：提出**自适应 LoRA 合并方法**，动态计算合并系数，使模型在增量学习中持续调整旧领域影响，高效适应新领域。

#### 2. 核心方法：自适应 LoRA 合并

**LoRA 基础**：

引入可训练矩阵 A 和 B，权重更新为 $  W = W_0 + BA  $，其中 r 为低秩秩（r≪d,k），大幅减少参数量。

**动态系数设计**：

系数 $  \alpha_i = \sigma(c_i) \cdot b  $，其中$\sigma$为 sigmoid 函数，$c_i$为可学习参数，$b=1+(b_{\text{max}}-1)\sigma(b_{\text{raw}})$确保$0<\alpha_i<b_{\text{max}}$，通过反向传播学习。

**算法流程**：逐个训练领域适配器，利用所有已见领域的平衡子集最小化交叉熵损失，动态更新合并系数，最终合并为$A_{\text{merged}} = \sum \alpha_i A_i$。

#### 3. 实验设置与结果

**数据集与基线**：

**基准**：PACS（照片、卡通、素描、艺术画）和 OfficeHome（4 个真实世界领域）。

**基线**：Task Arithmetic、TIES、DARE+TIES，测试固定权重 W∈{1,3,5}；自适应方法测试$b_{\text{max}}â{1.0,3.0,5.0}$，每类 1 或 5 个样本学习系数。

**关键实验结果**（见表 1-3）：

**固定权重敏感性**：PACS 中 TIES 在 W=1 时准确率 82.42%，W=5 时骤降至 16.14%，证明手动调参风险高。

**自适应优势**：

1 样本 / 类时，PACS 中 TIES 自适应方法（$b_{\text{max}}=3.0$）达 82.62%，与最优固定权重相当；OfficeHome 中 TIES 自适应在$b_{\text{max}}=3.0$时达 62.95%，优于多数固定权重结果。

5 样本 / 类时性能略升（如 PACS 中 TIES 达 82.84%），但 1 样本已接近最优，证明小样本高效性。

**系数动态调整**：卡通和素描领域因与预训练数据差异大，合并系数更高（$W>1.0$），模型自动分配更多注意力。

#### 4. 结论与价值

**创新点**：首次将 LoRA 合并用于 DIL，通过动态系数消除手动调参，仅需极少量样本学习权重。

**优势**：性能相当或优于固定方法，内存高效（仅存储适配器和系数），超参数简化（仅需设置$b_{\text{max}}$）。

**未来方向**：扩展至类增量学习、更复杂基准，探索多任务持续学习场景。

### 关键问题

#### 1. **现有 LoRA 合并算法在 DIL 中的主要缺陷是什么？**

**答案**：现有方法依赖**固定权重**，假设各任务重要性均等，需手动选择权重且无法动态适应新领域。例如，TIES 在 PACS 中不同权重（W=1 vs. W=5）准确率差异达 66.28%，证明固定权重对性能影响显著且调参成本高。

#### 2. **自适应 LoRA 合并方法如何实现动态调整？核心机制是什么？**

**答案**：通过**可学习的合并系数**实现。利用 sigmoid 函数和可学习参数生成系数$\alpha_i$，约束其在 (0, b\_max) 范围内，通过最小化平衡数据集上的交叉熵损失动态更新。例如，每新增一个领域，使用所有已见领域的少量样本（如 1 样本 / 类）训练系数，使模型自动分配各适配器的重要性（如卡通领域因分布差异大，系数高于 1.0）。

#### 3. **自适应方法在效率和性能上的核心优势是什么？**

**答案**：

**效率**：仅需**每类 1 个样本**学习系数，内存需求低（仅存储适配器和系数），无需全量数据 retrain。

**性能**：在 PACS 和 OfficeHome 上，自适应方法（如 TIES + 自适应）准确率与最优固定权重相当（如 PACS 中 82.62% vs. 固定 W=1 的 82.42%），且避免了手动调参风险，最坏情况下性能更稳定（如$b_{\text{max}}=3.0$时各领域准确率波动更小）。

# 自适应 LoRA 合并方法详细介绍

## 一、LoRA 基础回顾

在深入了解自适应 LoRA 合并方法之前，先回顾 LoRA（Low-Rank Adaptation）的基本原理。LoRA 是一种高效的大模型参数微调方法，其核心思想是在原有预训练模型的权重基础上，引入可训练的低秩矩阵来实现参数的高效更新。对于模型中的权重矩阵 $W_0 \in \mathbb{R}^{d \times k}$，LoRA 通过引入两个低秩矩阵 $A \in \mathbb{R}^{d \times r}$ 和 $B \in \mathbb{R}^{r \times k}$（其中 $r \ll d,k$，即低秩秩远小于原矩阵维度），将权重更新为 $W = W_0 + BA$。这样，在微调过程中，仅需更新低秩矩阵 $A$ 和 $B$，大幅减少了需要训练的参数数量，显著降低了计算成本和内存需求 。

## 二、自适应 LoRA 合并方法核心公式与符号解析

### （一）动态系数计算

自适应 LoRA 合并方法的关键在于动态计算合并系数，以此调整不同领域适配器的重要性。核心公式为：

$  \alpha_i = \sigma(c_i) \cdot b  $

其中：

$\alpha_i$ 表示第 $i$ 个领域适配器的合并系数，该系数用于确定在合并过程中该领域适配器的权重占比，从而动态调整模型对不同领域的适应程度。

$\sigma$ 是 sigmoid 函数，其表达式为 $\sigma(x) = \frac{1}{1 + e^{-x}}$，该函数将输入值映射到 $(0, 1)$ 区间，用于将可学习参数 $c_i$ 转化为合适的系数比例。

$c_i$ 是可学习参数，在训练过程中通过反向传播算法进行更新，模型通过学习 $c_i$ 来自动调整不同领域适配器的重要性。

$b$ 是一个缩放因子，用于进一步调整系数的范围，其计算公式为：

$  b = 1 + (b_{\text{max}} - 1) \cdot \sigma(b_{\text{raw}})  $

其中：

$b_{\text{max}}$ 是预先设定的最大缩放值，用于限制合并系数的上限，通过调整 $b_{\text{max}}$ 可以控制模型对不同领域的适应程度的灵活范围。

$b_{\text{raw}}$ 是另一个可学习参数，通过 sigmoid 函数与 $b_{\text{max}}$ 共同作用，确保 $0 < \alpha_i < b_{\text{max}}$，使得合并系数在合理范围内动态变化。

### （二）适配器合并过程

在计算出各领域适配器的合并系数后，进行适配器的合并操作。假设共有 $n$ 个领域适配器，每个适配器对应低秩矩阵 $A_i \in \mathbb{R}^{d \times r}$（$i = 1,2,\cdots,n$），合并后的低秩矩阵 $A_{\text{merged}}$ 计算公式为：

$  A_{\text{merged}} = \sum_{i = 1}^{n} \alpha_i A_i  $

该公式表示将各个领域的适配器矩阵 $A_i$ 按照计算得到的合并系数 $\alpha_i$ 进行加权求和，得到最终用于模型推理或进一步训练的合并适配器矩阵。通过这种方式，模型能够根据不同领域的重要性动态调整适配器的贡献，从而更好地适应领域增量学习中的动态变化。

## 三、方法案例演示

假设我们有一个图像分类任务，涉及三个不同领域的图像数据：自然风景图像（领域 1）、动物图像（领域 2）和人造建筑图像（领域 3），采用 ViT-B/16 作为基础模型，并使用 LoRA 进行微调。

### （一）训练阶段

首先，针对自然风景图像领域，训练第一个 LoRA 适配器，得到低秩矩阵 $A_1$ 和 $B_1$，此时可学习参数 $c_1$ 和 $b_{\text{raw}}$ 随机初始化。

接着，引入动物图像领域，利用所有已见领域（即自然风景图像和动物图像）的平衡子集数据（假设每类选取 1 个样本），构建一个用于计算合并系数的训练集。在训练过程中，通过最小化交叉熵损失函数，不仅更新动物图像领域的 LoRA 适配器的低秩矩阵 $A_2$ 和 $B_2$，同时更新可学习参数 $c_1$、$c_2$ 和 $b_{\text{raw}}$。根据公式 $\alpha_i = \sigma(c_i) \cdot b$ 计算出 $\alpha_1$ 和 $\alpha_2$，然后按照 $A_{\text{merged}} = \alpha_1 A_1 + \alpha_2 A_2$ 合并适配器矩阵。

最后，加入人造建筑图像领域，同样利用所有已见领域（自然风景、动物、人造建筑图像）的平衡子集数据，更新该领域的 LoRA 适配器的低秩矩阵 $A_3$ 和 $B_3$，以及可学习参数 $c_1$、$c_2$、$c_3$ 和 $b_{\text{raw}}$。重新计算合并系数 $\alpha_1$、$\alpha_2$ 和 $\alpha_3$，并通过 $A_{\text{merged}} = \alpha_1 A_1 + \alpha_2 A_2 + \alpha_3 A_3$ 得到最终的合并适配器矩阵。

### （二）推理阶段

在推理时，将输入的图像数据输入到经过自适应 LoRA 合并后的模型中，模型利用合并后的适配器矩阵 $A_{\text{merged}}$ 和对应的 $B_{\text{merged}}$（计算方式与 $A_{\text{merged}}$ 类似）对图像进行特征提取和分类预测。由于合并系数是根据不同领域数据动态学习得到的，模型能够更合理地权衡各个领域适配器的作用，从而在不同领域的图像分类任务中表现出较好的性能 。

通过上述案例可以清晰地看到自适应 LoRA 合并方法如何在实际的领域增量学习任务中，通过动态计算合并系数实现对不同领域适配器的有效整合，提高模型的适应性和泛化能力。
