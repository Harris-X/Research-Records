# 《NeuroMerging：基于神经元子空间分解的无训练模型融合框架》

### 一段话总结

本文针对模型合并中的**任务干扰问题**，首次探索了**神经元对齐**的作用，将任务特定表示分解为调节神经元敏感性的**平行子空间**和输入适应性的**正交子空间**，提出无训练模型融合框架**NeuroMerging**。通过在视觉和自然语言处理多任务基准上的实验，证明该方法在域内、域外泛化性能上均优于现有技术（如 T5-Large 模型合并中平均提升 1.2%），强调了神经元机制对齐对缓解任务干扰和提升知识融合的重要性。

### 详细总结

#### 1. 研究背景与挑战

**问题定位**：预训练模型微调后通过模型合并整合多任务能力时，**任务干扰**导致性能下降，现有方法（模型 / 层 / 参数级）忽略**神经元级机制**，缺乏解释性。

**核心观察**：神经元在微调中通过两个互补子空间变化 —— 保留正交子空间（任务特定适应）可维持性能，而平行子空间（共享表征）主导时性能骤降（如图 1）。

#### 2. 方法：NeuroMerging 框架

**神经元任务向量**：定义为微调与预训练模型的神经元权重差（τₜᵏ = wₜᵏ - w₀ᵏ），聚焦前 r% 关键参数（掩码处理）。

**子空间分解**：

**平行子空间（P）**：τₜ,∥ᵏ = Pτₜᵏ，投影到预训练权重空间，反映神经元对输入变化的敏感性。

**正交子空间（O）**：τₜ,⊥ᵏ = (I-P)τₜᵏ，捕获任务特定适应，决定输入适应性。

**合并策略**：

$ 
  \bar{\tau}^k = \lambda_1\psi_{\|}(\tau_{\|,1}^k, ..., \tau_{\|,T}^k) + \lambda_2\psi_{\perp}(\tau_{\perp,1}^k, ..., \tau_{\perp,T}^k)
   $

无验证集时：λ₁=0（平行子空间影响小），λ₂=1/(1-σ)（σ 为掩码比例相关系数）。

验证集可用时：通过 SVD 优化正交子空间合并。

#### 3. 实验结果

**NLP 任务（T5 模型）**：

| 方法                   | T5-Base 平均精度 | T5-Large 平均精度 |
| -------------------- | ------------ | ------------- |
| 现有 SOTA（PCB-Merging） | 76.9%        | 81.0%         |
| NeuroMerging         | **77.5%**    | **82.2%**     |

优势：域内任务平均提升 0.6%-1.2%，域外泛化（T0 基准）提升 0.5%-0.7%。

**CV 任务（ViT 模型）**：

| 方法 | ViT-B/32 平均精度 | ViT-L/14 平均精度 |
| ---- | ----------------- | ----------------- |
| 现有 SOTA（PCB-Merging） | 76.3%          | 87.5%            |
| NeuroMerging（无验证）| **76.4%**      | **87.9%**        |
| NeuroMerging（有验证）| **76.5%**      | **88.3%**        |

优势：在遥感、交通标志等 8 个任务上超越基线，无验证集场景优势更显著。

**LLM 任务（Llama-2-7B）**：

合并中文理解、数学推理、代码生成模型，平均精度 36.0%，超越 PCB-Merging+ES（35.3%）0.7%，尤其数学推理提升 3.1%。

**消融实验**：

保留正交子空间时，T5-Large 域内精度 88.0%（接近微调模型），而仅保留平行子空间时骤降至 52.7%（表 6）。

合并函数选择：TIES-Merging 的 “elect+mean” 策略最优（平均 82.2%），验证子空间分解的鲁棒性。

#### 4. 核心贡献与意义

**理论创新**：首次揭示神经元对齐在模型合并中的作用，提出双互补子空间理论。

**方法突破**：首个神经元级模型合并框架，无训练、轻量高效，参数效率比 RegMean 等提升 50% 以上。

**应用价值**：跨模态（NLP/CV/LLM）泛化，为多任务模型构建提供新范式，尤其适用于隐私敏感场景。

#### 5. 局限性与未来方向

未探索神经元组同步交互及动态机制，仅聚焦静态权重分解。

依赖同预训练模型的微调模型，跨架构合并效果未知。

未来可扩展至多模态模型、更大规模架构（如 GPT-4）及在线动态合并。

### 关键问题与答案

#### 问题 1：NeuroMerging 如何通过神经元子空间分解缓解任务干扰？

**答案**：通过将任务向量分解为**平行子空间（P）和正交子空间（O）**：

P 子空间捕获与预训练模型的共享表征，对输入敏感性高但易引发任务冲突；

O 子空间捕获任务特定适应，通过 SVD 优化正交方向的合并，减少不同任务在参数空间的竞争。实验表明，保留 O 子空间可维持 90% 以上任务性能，而仅保留 P 子空间导致性能下降 40%（表 6）。

#### 问题 2：NeuroMerging 在无验证集场景下的优势是什么？

**答案**：无验证集时，通过**L1 范数动态调整权重**（λ₂=1/(1-σ)），避免依赖额外数据：

NLP 任务中，T5-Base 无验证集精度 74.8%，超越现有 SOTA（PCB-Merging, 73.4%）1.4%；

CV 任务中，ViT-L/14 无验证集精度 87.9%，比有验证集的 RegMean（83.7%）高 4.2%。该策略通过掩码比例自动平衡任务特定参数，提升泛化性和实用性。

#### 问题 3：论文在模型合并的粒度上有何突破？

**答案**：现有方法限于**模型级、层级、参数级**，而本文首次聚焦**神经元级**：

发现神经元参数占比超 99.9%（T5 模型，图 5），是影响任务适应的核心单元；

通过神经元任务向量分解，实现细粒度的知识融合，例如在 Llama-2 模型中，数学推理任务精度从 53.1%（PCB-Merging+ES）提升至 57.2%（NeuroMerging），证明神经元级操作的有效性。



# 《NeuroMerging 框架：神经元子空间分解与合并策略》

在 NeuroMerging 框架中，方法设计围绕神经元子空间分解与合并策略展开，以下将结合公式与符号详细介绍其核心内容：

**神经元任务向量定义**

为了捕捉微调对神经元的影响，论文定义**神经元任务向量**为微调后模型与预训练模型的神经元权重差，公式为：$\tau_{t}^{k} = w_{t}^{k} - w_{0}^{k}$。其中，$w_{t}^{k}$ 代表在任务 $t$ 下，第 $k$ 个神经元的权重；$w_{0}^{k}$ 则是预训练模型中第 $k$ 个神经元的权重。通过该向量，能够清晰量化每个神经元因任务微调产生的变化。

同时，考虑到并非所有神经元对任务的贡献相同，论文引入掩码机制，聚焦前 $r\%$ 关键参数 ，仅保留这些重要神经元的任务向量，以提升计算效率和模型性能。

**子空间分解**

**平行子空间（**** ****）**：平行子空间旨在捕获与预训练模型共享的表征，反映神经元对输入变化的敏感性。将神经元任务向量 $\tau_{t}^{k}$ 投影到预训练权重空间，得到平行子空间的任务向量：$\tau_{t,\parallel}^{k} = P\tau_{t}^{k}$。这里的 $P$ 是投影矩阵，通过这种投影操作，提取出神经元中与预训练知识相关的部分。

**正交子空间（**** ****）**：正交子空间用于捕获微调引入的任务特定适应，决定输入适应性。其任务向量通过从原始任务向量中减去平行子空间向量得到：$\tau_{t,\perp}^{k} = (I - P)\tau_{t}^{k}$，其中 $I$ 是单位矩阵。该操作使得正交子空间专注于任务微调带来的独特变化，与平行子空间形成互补。

**合并策略**

合并多个任务的神经元向量时，采用如下公式：$\bar{\tau}^{k} = \lambda_{1}\psi_{\parallel}(\tau_{\parallel,1}^{k}, ..., \tau_{\parallel,T}^{k}) + \lambda_{2}\psi_{\perp}(\tau_{\perp,1}^{k}, ..., \tau_{\perp,T}^{k})$ 。其中，$\bar{\tau}^{k}$ 是合并后的第 $k$ 个神经元向量；$\psi_{\parallel}$ 和 $\psi_{\perp}$ 分别是平行子空间和正交子空间的合并函数，常用平均或加权平均等方式；$T$ 表示任务总数；$\lambda_{1}$ 和 $\lambda_{2}$ 是平衡两个子空间贡献的权重系数 。

**无验证集场景**：当没有验证集时，根据实验经验设定 $\lambda_{1}=0$，即暂时忽略平行子空间的影响（因其易引发任务冲突），$\lambda_{2}=\frac{1}{1 - \sigma}$ ，其中 $\sigma$ 是与掩码比例相关的系数。该设定通过 L1 范数动态调整权重，实现任务特定参数的自动平衡。

**有验证集场景**：若存在验证集，则通过奇异值分解（SVD）优化正交子空间的合并，以找到最佳的权重组合，进一步提升模型在多任务场景下的性能 。

通过以上公式与策略，NeuroMerging 框架从神经元层面实现了对任务特定表示的分解与融合，有效缓解模型合并中的任务干扰问题，为多任务模型的构建提供了创新思路。 若你还想了解该方法在实验中的具体表现，或是对某些公式有更深入的疑问，欢迎随时和我说。
