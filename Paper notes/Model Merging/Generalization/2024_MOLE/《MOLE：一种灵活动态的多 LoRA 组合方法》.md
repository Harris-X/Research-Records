# 《MOLE：一种灵活动态的多 LoRA 组合方法》

\*

***

**一段话总结**：本文提出 \*\* 混合低秩自适应专家（MOLE）\*\* 方法，旨在解决多个训练好的低秩自适应（LoRA）模块组合的难题。当前 LoRA 组合方法，如线性算术组合会削弱模型生成能力或特性，基于参考调整的组合适应性受限且计算成本高。MOLE 将每层训练好的 LoRA 视为独立专家，通过可学习门控函数实现分层权重控制，学习特定领域目标的最优组合权重。在自然语言处理和视觉与语言领域的实验表明，MOLE 性能优于现有方法，且计算开销小、灵活性高，但在处理大规模 LoRA 组合时仍存在性能下降的问题。

**思维导图**



```mindmap
## **研究背景**
- 大规模预训练模型发展带来计算成本问题
- LoRA组合方法存在局限性
## **方法介绍**
- 提出MOLE，基于门控函数实现分层权重控制
- 引入门控平衡损失和领域特定损失优化
## **实验结果**
- 在V&L领域，文本和图像对齐分数更高
- 在NLP领域，多个任务上优于基线方法

- 门控平衡损失提升性能

- 大规模LoRA组合时性能下降待解决
```

**详细总结**：

**研究背景**：深度学习中大规模预训练模型在多任务表现出色，但全量微调计算成本高，LoRA 作为高效微调方法被广泛应用。现有 LoRA 组合方法主要有线性算术组合和基于参考调整的组合，前者直接组合会影响模型生成能力，归一化后又会损失 LoRA 特性；后者存在组合灵活性差和计算成本高的问题。

**方法介绍**：

**设计理念**：提出**混合低秩自适应专家（MOLE）**，将训练好的 LoRA 每层视为独立专家，通过可学习门控函数在每层学习最优组合权重，实现分层权重控制。

**计算过程**：在预训练模型的 Transformer 块中，输入经预训练模型块和各 LoRA 模块处理后，门控函数对各 LoRA 输出进行拼接、归一化等操作，计算出各 LoRA 的门控值，最终输出是门控函数输出与预训练网络输出之和。

**训练目标**：引入 \*\* 门控平衡损失（$L_{balance}$）\*\* 避免门控函数收敛到仅少数 LoRA 有影响的状态；针对不同领域采用特定训练目标（$L_{D}$），总训练目标为两者加权和，训练时仅优化门控函数参数。

**实验结果**：

**V\&L 领域**：以 DreamBooth 为基础生成多概念图像，对比归一化线性算术组合和 SVDiff 等方法，MOLE 在文本对齐分数上平均提升 0.031，在图像对齐（概念 1）上平均提升 0.037，生成图像能更好保留用户指定主体，提高主体保真度。

**NLP 领域**：基于 Flan-T5 模型进行多任务实验，对比 LoRAhub 和 PEMs 等方法，在 BBH 数据集上，MOLE 比 LoRAHub 平均性能提升 3.8，比 PEMs 高 9.0；在翻译和结构化文本生成任务中也表现更优。

**分析讨论**：

**门控平衡损失有效性**：门控平衡损失使门控函数权重分布更均匀，仅增加温度 τ 会限制动态探索，导致性能下降。

**与其他方法对比**：在 V\&L 领域，MOLE 比不使用 LoRA 的全参数训练方法表现更好且更轻量；在 NLP 和 V\&L 领域，随着 LoRA 数量增加，MOLE 性能优势明显，但 LoRA 数量过大（如 128）时所有方法性能都会下降。

**门控粒度分析**：不同粒度门控实验表明，块级（b-MOLE）和层级（l-MOLE）门控性能最佳，网络级（n-MOLE）和矩阵级（m-MOLE）表现较差。

**泛化能力**：在新数据集上的实验显示，MOLE 比 LoRAHub 平均性能优势为 2.4，比 PEMs 高 3.7，泛化能力强。

**灵活性**：MOLE 能保留 LoRA 特征，可通过掩码操作灵活调整组合，实现不同的 LoRA 组合效果。

**研究结论**：MOLE 是一种灵活动态的多 LoRA 组合方法，在 NLP 和 V\&L 领域优于现有方法，但在处理大量 LoRA 组合时性能会下降，需进一步研究更好的处理方法。

**关键问题**：

**问题 1**：MOLE 与传统 LoRA 组合方法的本质区别是什么？

**答案**：传统 LoRA 组合方法如线性算术组合直接相加或归一化相加，易损失模型生成能力或 LoRA 特性；基于参考调整的组合灵活性差且计算成本高。MOLE 本质上是将每层 LoRA 视为独立专家，通过可学习门控函数实现分层权重控制，能动态优化组合权重，更好地保留 LoRA 特性，且计算开销小、灵活性高。

**问题 2**：门控平衡损失在 MOLE 中起到了怎样的作用？

**答案**：门控平衡损失（$L_{balance}$）用于避免门控函数在训练过程中收敛到总是为早期表现好的 LoRA 分配大权重的状态，使得门控函数的概率分布熵不会随训练步数增加而过度减小，从而保证组合权重分布更均匀，避免仅少数 LoRA 起主要作用，有效提升了 MOLE 的性能。

**问题 3**：MOLE 在大规模 LoRA 组合时性能下降，可能的原因有哪些？

**答案**：可能原因一是随着 LoRA 数量大幅增加，模型参数复杂度急剧上升，现有优化算法难以有效处理，导致无法充分学习到各 LoRA 之间的协同关系；二是过多的 LoRA 可能引入冗余或冲突信息，干扰了模型对有效信息的捕捉和利用，使得模型性能受到影响 。



# MOLE方法介绍

### 设计理念

混合低秩自适应专家（MOLE）是一种创新的方法，其核心在于将训练好的低秩自适应（LoRA）每层都视为独立的专家 。传统的 LoRA 组合方法存在诸多弊端，比如线性算术组合，直接相加会损害模型的生成能力，而归一化相加又会致使 LoRA 的特性丧失；基于参考调整的组合则面临灵活性欠佳以及计算成本高昂的问题。MOLE 另辟蹊径，通过可学习门控函数，在每一层学习到最优的组合权重，从而实现对权重的分层控制，有效克服了传统方法的缺陷。

### 计算过程

在预训练模型的 Transformer 块中，其计算过程较为复杂且精妙。输入数据首先经过预训练模型块的处理，得到一个输出。同时，输入数据也会分别进入各个 LoRA 模块进行处理。接下来，门控函数会对各 LoRA 模块的输出进行一系列操作。先将这些输出进行拼接，然后对拼接后的结果进行归一化等操作，进而计算出各个 LoRA 的门控值。最终的输出则是门控函数的输出与预训练网络输出之和 。

用数学公式来详细解释这一过程：假设预训练模型块的输出为$H_{PT}$，有$K$个 LoRA 模块，第$k$个 LoRA 模块的输出为$H_{LoRA}^k$。门控函数首先对所有 LoRA 模块的输出进行拼接，得到$H_{concat}=[H_{LoRA}^1;H_{LoRA}^2;\cdots;H_{LoRA}^K]$ 。然后对$H_{concat}$进行归一化，这里可以使用 softmax 函数进行归一化，得到门控值$\alpha^k$ ，$\alpha^k = \frac{\exp(H_{LoRA}^k\cdot W_g)}{\sum_{i = 1}^{K}\exp(H_{LoRA}^i\cdot W_g)}$，其中$W_g$是门控函数中的可学习参数 。最终的输出$H_{final}=H_{PT}+\sum_{k = 1}^{K}\alpha^k H_{LoRA}^k$ 。在这个过程中，$H$代表张量，其维度根据 Transformer 块的结构和 LoRA 模块的设置而定，例如在常见的 Transformer 结构中，输入输出张量可能是 (batch\_size, sequence\_length, hidden\_size) 这样的维度 。

### 训练目标

为了使 MOLE 能够更好地发挥作用，其训练目标包含两个关键部分。一是引入门控平衡损失（$L_{balance}$），这个损失的作用至关重要，它主要是为了避免门控函数在训练过程中收敛到一种不理想的状态，即总是为早期表现较好的 LoRA 分配较大的权重，而使得其他 LoRA 的权重被忽视。通过$L_{balance}$，可以确保门控函数的概率分布熵不会随着训练步数的增加而过度减小，从而让组合权重的分布更加均匀 。

$L_{balance}=-\sum_{k = 1}^{K}\alpha^k\log(\alpha^k)$，其中$\alpha^k$就是前面提到的门控值 。

二是针对不同的领域采用特定的训练目标（$L_{D}$），这个训练目标是根据具体的任务和领域来设计的，比如在自然语言处理任务中，可能是交叉熵损失用于分类任务，或者是基于语言模型的困惑度损失等；在视觉与语言领域，可能是基于图像和文本对齐的损失等 。总的训练目标$L$就是两者的加权和，即$L=\lambda L_{balance}+(1 - \lambda)L_{D}$，其中$\lambda$是一个超参数，用于平衡两种损失的重要性 。在整个训练过程中，只对门控函数中的参数（如$W_g$）进行优化，而预训练模型和 LoRA 模块的参数保持不变 。

### 方法案例

以自然语言处理中的文本分类任务为例，假设我们有一个基于预训练模型（如 BERT）的文本分类模型，并且已经在不同的数据集上分别训练了多个 LoRA 模块。一个 LoRA 模块是在新闻文本分类数据集上训练的，它擅长捕捉新闻文本中的主题信息；另一个 LoRA 模块是在社交媒体文本分类数据集上训练的，它对社交媒体文本中的情感倾向和流行话题相关特征较为敏感 。

当使用 MOLE 方法时，输入一段待分类的文本，首先经过预训练的 BERT 模型块得到一个基础的特征表示。然后，该文本分别进入这两个 LoRA 模块，新闻 LoRA 模块输出与新闻主题相关的特征，社交媒体 LoRA 模块输出与情感和流行话题相关的特征。门控函数根据这些输出，通过前面所述的计算过程，为新闻 LoRA 模块和社交媒体 LoRA 模块分别计算出一个门控值，比如新闻 LoRA 模块的门控值为 0.6，社交媒体 LoRA 模块的门控值为 0.4。最后，将预训练 BERT 模型块的输出，与经过门控值加权后的两个 LoRA 模块的输出相加，得到最终用于文本分类的特征表示 。根据最终的特征表示，通过一个简单的分类器（如全连接层）就可以预测文本的类别 。在这个案例中，MOLE 方法通过动态地调整两个 LoRA 模块的权重，能够更好地利用不同 LoRA 模块的优势，从而提高文本分类的准确性 。

在视觉与语言领域，比如图像描述生成任务。假设有一个基于预训练的视觉语言模型（如 CLIP），并且有两个 LoRA 模块。一个 LoRA 模块在大量人物图像和对应描述数据上训练，对人物相关的视觉特征和描述语言的关联学习得很好；另一个 LoRA 模块在风景图像和对应描述数据上训练，擅长处理风景相关的信息 。输入一张包含人物和风景的图像时，预训练模型先提取图像的整体特征。然后，两个 LoRA 模块分别基于自身训练的特点对图像特征进行进一步处理。门控函数计算出人物 LoRA 模块的门控值为 0.3，风景 LoRA 模块的门控值为 0.7 。最终，将预训练模型输出与加权后的两个 LoRA 模块输出相加，用于生成图像描述。由于 MOLE 能够根据图像内容动态调整不同 LoRA 模块的权重，生成的图像描述能够更准确地兼顾图像中的人物和风景元素 。
