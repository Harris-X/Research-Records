# **Frequency-aware Event Cloud Network**

## 摘要

事件相机是一种受生物学启发的传感器，能够异步地发出事件，具有显著的时间分辨率，引起了工业界和学术界的广泛关注。主流方法倾向于使用帧和体素表示，虽然达到了令人满意的性能，但引入了耗时的转换、庞大的模型，并牺牲了细粒度的时间信息。作为一种替代方案，点云表示在解决上述问题方面显示出潜力，但它忽略了极性信息，其模型在抽象长期事件特征方面的能力有限。在本文中，我们提出了一种名为FECNet的频率感知网络，该网络利用事件云表示。FECNet充分利用了2S-1T-1P事件云，通过创新的事件基团和采样模块。为了适应事件云中的长序列事件，FECNet采用傅里叶变换在频域中进行特征提取。这种方法显著减少了乘累加操作（MACs）的使用，同时有效地抽象了时空特征。我们在基于事件的对象分类、动作识别和人体姿态估计任务上进行了广泛的实验，结果充分证明了FECNet的有效性和效率。我们的代码可在https://github.com/rhwxmx/FECNet获取。
